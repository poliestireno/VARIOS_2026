01

Variables y funciones

El script se enlaza con <script src="app.js"></script>, normalmente justo antes de </body> — así, cuando se ejecuta, el HTML de encima ya existe en la página.

let puntos = 0;              // variable que puede cambiar
const MAX_INTENTOS = 4;     // constante, no se reasigna

function sumarPunto() {
  puntos = puntos + 1;
  console.log("Puntos:", puntos);
}

console.log() es la herramienta de depuración más usada: escribe en la consola del navegador (pestaña Console de las DevTools, F12), sin interrumpir la página como haría un alert().

02

Seleccionar elementos: el DOM

El DOM (Document Object Model) es la representación del HTML como un árbol de objetos que JavaScript puede leer y modificar. document.querySelector() busca el primer elemento que coincida con un selector CSS — el mismo tipo de selector que en una hoja de estilos.

const titulo = document.querySelector("h1");
const tarjeta = document.querySelector(".tarjeta");
const marcador = document.querySelector("#marcador");
const todasLasTarjetas = document.querySelectorAll(".tarjeta"); // varias, como una lista

marcador.textContent = "3 - 2";        // cambia el texto
tarjeta.style.display = "none";   // la oculta
tarjeta.classList.add("activa");     // añade una clase CSS
tarjeta.classList.toggle("parpadea");  // la quita si la tiene, la pone si no

classList.toggle() es especialmente útil para animaciones con CSS: se define la animación (por ejemplo, un parpadeo) en una clase CSS, y JavaScript solo añade o quita esa clase según haga falta.

03

Eventos

addEventListener() ejecuta una función cuando ocurre algo — un clic, el envío de un formulario, que termine de cargar la página…

const porteria = document.querySelector(".porteria");

porteria.addEventListener("click", function (evento) {
  console.log("¡Gol!");
});

// forma corta, con función flecha
porteria.addEventListener("click", () => {
  puntos++;
});

Los dos ejemplos hacen lo mismo; la función flecha (() => {}) es solo una forma más corta de escribir una función, muy habitual como manejador de eventos.

04

Leer formularios

Para leer lo que el usuario ha escrito, primero se evita que el formulario recargue la página (preventDefault()), y después se lee cada campo por su value.

const form = document.querySelector("form");

form.addEventListener("submit", (evento) => {
  evento.preventDefault();  // evita que la página se recargue

  const nombre = document.querySelector("#nombre").value;
  const clave = document.querySelector("#clave").value;

  console.log(`Hola ${nombre}`);
});

Las comillas invertidas (`...`) crean una template string: dentro se puede insertar cualquier variable con ${variable}, sin concatenar con +.

05

Pasar datos entre páginas

Cuando el "siguiente paso" es otro archivo .html (navegación real, no una sola página que cambia de vista), las variables de JavaScript no sobreviven al cambio de página — hace falta guardarlas en algún sitio que si sobreviva.

localStorage

Guarda pares clave/valor en el navegador, que persisten aunque se cierre la pestaña. Solo admite texto, así que los datos que no sean cadenas se convierten con JSON.stringify() / JSON.parse().

// página 1: guardar
const datos = { nombre: "Ana", contador1: 5 };
localStorage.setItem("miApp", JSON.stringify(datos));
window.location.href = "pagina2.html"; // navega a la siguiente página

// página 2: leer y ampliar
const datosPrevios = JSON.parse(localStorage.getItem("miApp"));
datosPrevios.contador2 = 21;
localStorage.setItem("miApp", JSON.stringify(datosPrevios));

Parámetros en la URL

Alternativa sin guardar nada en el navegador: mandar los datos como parte de la propia URL (?nombre=Ana&edad=20), y leerlos con URLSearchParams.

const parametros = new URLSearchParams(window.location.search);
const nombre = parametros.get("nombre"); // "Ana"
¿Cuál usar?

localStorage es más cómodo cuantos más datos se acumulan (no hay que arrastrar una URL cada vez más larga entre 4 páginas), y no muestra la información en la barra de direcciones. Los parámetros de URL son más simples para un dato suelto y permiten compartir el enlace ya relleno.

06

Reproducir sonido

Más allá de la etiqueta <audio controls> (ver Fundamentos de HTML), JavaScript puede lanzar un sonido corto en el momento justo — por ejemplo, un gol o una parada en un minijuego.

const sonidoGol = new Audio("sonidos/gol.mp3");

porteria.addEventListener("click", () => {
  sonidoGol.currentTime = 0; // rebobina, por si sonaba de un clic anterior
  sonidoGol.play();
});

currentTime = 0 antes de play() evita que, si el usuario dispara varias veces seguidas muy rápido, el sonido se quede a medias en vez de volver a sonar desde el principio.

Autoplay bloqueado

La mayoría de navegadores bloquean reproducir audio automáticamente al cargar la página, sin que el usuario haya interactuado antes. Si el sonido no sale al probarlo, comprueba que se está lanzando dentro de un evento de clic (o similar), no en el primer load de la página.

Con esto ya se puede construir cualquiera de los desafíos del módulo: formularios encadenados, un minijuego con estado y sonido, o una réplica interactiva de una página real.
