01

Instalación por CDN

La forma más rápida de usar Bootstrap es enlazarlo desde un CDN, sin instalar nada: una línea de CSS en el <head>, y una de JavaScript justo antes de cerrar </body> (necesaria para los componentes interactivos: menús desplegables, modales…).

<head>
  ...
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  ...
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>

A partir de ahí, Bootstrap funciona con clases CSS sobre HTML normal — no hay que aprender una sintaxis nueva, solo memorizar (o buscar) los nombres de clase adecuados.

02

El sistema de rejilla

Bootstrap divide el ancho disponible en 12 columnas. Tres niveles anidados: container (centra y limita el ancho máximo) → row (una fila) → col-* (cuánto ocupa cada columna, de 1 a 12).

<div class="container">
  <div class="row">
    <div class="col-4">Un tercio</div>
    <div class="col-8">Dos tercios</div>
  </div>
  <div class="row">
    <div class="col">Igual</div>
    <div class="col">Igual</div>
    <div class="col">Igual</div>
  </div>
</div>

col-4 + col-8 suman 12: el primer bloque ocupa un tercio, el segundo dos tercios. Un col sin número reparte el espacio a partes iguales entre todos los que haya en esa fila.

03

Breakpoints responsive

Cada clase col-* tiene variantes con infijo de tamaño de pantalla — se pueden combinar varias en el mismo elemento, y cada una manda a partir de su ancho mínimo hacia arriba (mobile-first).

InfijoSe activa desde…
col-Siempre (móvil incluido).
col-sm-≥ 576px.
col-md-≥ 768px (tablet).
col-lg-≥ 992px (portátil).
col-xl-≥ 1200px (escritorio grande).
<div class="col-12 col-md-6 col-lg-4">Tarjeta</div>

Esta tarjeta ocupa todo el ancho en móvil (col-12), la mitad en tablet (col-md-6, dos por fila) y un tercio en pantallas grandes (col-lg-4, tres por fila) — sin escribir una sola media query.

04

Componentes comunes

Navbar

<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <div class="container">
    <a class="navbar-brand" href="index.html">Mi Garito</a>
    <div class="navbar-nav">
      <a class="nav-link" href="fiesta.html">La fiesta</a>
    </div>
  </div>
</nav>

Card (tarjeta)

<div class="card" style="width: 18rem;">
  <img src="cartel.jpg" class="card-img-top" alt="Cartel de la fiesta">
  <div class="card-body">
    <h5 class="card-title">Noche de Halloween</h5>
    <p class="card-text">31 de octubre, 23:00.</p>
    <a href="#" class="btn btn-primary">Reservar</a>
  </div>
</div>

Los botones (btn) llevan un color de la paleta del tema: btn-primary, btn-danger, btn-success, btn-outline-dark (solo borde)… La lista completa de componentes (modales, acordeones, carruseles, formularios con validación) está en la documentación oficial.

05

Clases de utilidad

Además de componentes completos, Bootstrap trae cientos de clases sueltas de una sola propiedad — útiles para ajustes rápidos sin salir del HTML ni tocar una hoja de estilos.

ClaseEquivale a
d-flexdisplay: flex
mt-3 / mb-3 / m-3margen arriba / abajo / en todos los lados (escala 0–5)
p-4padding en los cuatro lados (escala 0–5)
text-centertext-align: center
fw-boldfont-weight: bold
roundedesquinas redondeadas
shadowsombra suave
<div class="d-flex justify-content-center p-4 mt-3 rounded shadow">
  Centrado, con aire y sombra — sin abrir un archivo .css
</div>
06

Consejos finales

  • No hace falta memorizar las clases: la documentación oficial tiene ejemplos de copiar y pegar para cada componente.
  • Un sitio de varias páginas queda más coherente si la navbar y el pie de página se repiten idénticos en todas ellas — cópialos tal cual entre archivos.
  • Bootstrap no impide usar CSS propio encima — enlaza tu propia hoja de estilos después de la de Bootstrap para poder sobreescribir lo que haga falta.
  • El grid es mobile-first: diseña primero pensando en móvil (una columna, col-12) y añade breakpoints más grandes solo donde de verdad aporten algo.
