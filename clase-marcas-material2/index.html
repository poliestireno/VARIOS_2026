Bloque 1 · 34% de la evaluación

RA1 + RA2 · Fundamentos de HTML y CSS

3 desafíos · 21 días de grupo · Eval. 1

RA1. Reconoce las características de lenguajes de marcas analizando e interpretando fragmentos de código. RA2. Utiliza lenguajes de marcas para la transmisión de información a través de la Web analizando la estructura de los documentos e identificando sus elementos.

Teoría

T0

Fundamentos de HTML

Estructura básica, texto y semántica, enlaces, imágenes y multimedia (audio/vídeo), tablas, formularios, y buenas prácticas de accesibilidad.

T1

Fundamentos de CSS

Selectores y cascada, el modelo de caja, Flexbox, Grid, posicionamiento (para carteles y réplicas exactas), diseño responsive, y cómo clonar una página con las DevTools.

T2

Bootstrap 5

Instalación por CDN, el sistema de rejilla de 12 columnas, breakpoints responsive, componentes comunes (navbar, cards, botones) y clases de utilidad.

Bloque 2 · 33% de la evaluación

RA3 + RA4 · JavaScript y proyectos con formularios

4 desafíos · 28 días de grupo · Eval. 2

RA3. Genera canales de contenidos analizando y utilizando tecnologías de sindicación. RA4. Establece mecanismos de validación para documentos XML utilizando métodos para definir su sintaxis y estructura. En la práctica, este bloque se centra en JavaScript en el navegador (DOM, eventos, formularios) y en profundizar el HTML/CSS del bloque 1 con proyectos más creativos.

Teoría

T3

JavaScript, DOM y formularios

Variables y funciones, seleccionar elementos del DOM, eventos, leer formularios, pasar datos entre páginas (localStorage y parámetros de URL), y reproducir sonido.

Bloque 3 · 33% de la evaluación

RA5 + RA6 · Proyectos avanzados: réplicas y minijuegos

3 desafíos · 21 días de grupo · Eval. 3

RA5. Realiza conversiones sobre documentos XML utilizando técnicas y herramientas de procesamiento. RA6. Gestiona información en formato XML analizando y utilizando tecnologías de almacenamiento y lenguajes de consulta. En la práctica, este bloque no introduce teoría nueva: combina y exige más precisión en el HTML, CSS y JavaScript ya vistos en los bloques 1 y 2 — replicar una página al detalle, o programar el estado completo de un minijuego.
