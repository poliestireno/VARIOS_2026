01

Selectores y cascada

CSS se enlaza con <link rel="stylesheet" href="estilos.css"> dentro del <head>. Cada regla es un selector (a qué elementos aplica) más un bloque de declaraciones (propiedad: valor).

h1 {                 /* por etiqueta */
  color: #E44D26;
}
.tarjeta {           /* por clase: class="tarjeta" */
  border-radius: 8px;
}
#cabecera {          /* por id: id="cabecera", único en la página */
  background: black;
}
.tarjeta h2 {        /* descendiente: h2 dentro de .tarjeta */
  margin-top: 0;
}
.tarjeta:hover {     /* pseudo-clase: al pasar el ratón */
  box-shadow: 0 4px 12px rgba(0,0,0,.2);
}

Cuando dos reglas afectan al mismo elemento, gana la más específica (un id gana a una clase, una clase gana a una etiqueta); a igualdad de especificidad, gana la que aparece más abajo en el archivo. Es la "cascada" que le da nombre a CSS.

02

El modelo de caja

Todo elemento HTML es, para CSS, una caja rectangular con cuatro capas, de dentro hacia fuera: contenido, padding (espacio interior), border (borde) y margin (espacio exterior, entre cajas).

* {
  box-sizing: border-box; /* casi siempre, ver aviso debajo */
}
.tarjeta {
  width: 300px;
  padding: 16px;
  border: 2px solid #333;
  margin: 0 auto 20px; /* auto centra horizontalmente */
}
content-box vs. border-box

Por defecto (content-box), width mide solo el contenido, y el padding/borde se suman por fuera — una caja de width: 300px con padding: 16px mide en realidad 332px. Con box-sizing: border-box, width pasa a incluir padding y borde — la caja mide exactamente 300px. Por eso casi todo el mundo pone box-sizing: border-box en * al principio de cada hoja de estilos.

03

Flexbox

Flexbox reparte espacio en una dimensión (fila o columna). Se activa en el contenedor padre; los hijos se acomodan solos.

.barra-botones {
  display: flex;
  flex-direction: row;             /* row (defecto) o column */
  justify-content: space-between; /* eje principal */
  align-items: center;          /* eje cruzado */
  gap: 12px;                     /* hueco entre hijos, sin márgenes sueltos */
}

justify-content reparte el espacio sobrante a lo largo del eje principal (flex-start, center, space-between, space-around…); align-items alinea en el eje perpendicular. Es la herramienta natural para una barra de navegación, una fila de tarjetas, o centrar cualquier cosa vertical y horizontalmente a la vez (justify-content: center; align-items: center;).

04

Grid

Grid reparte espacio en dos dimensiones a la vez (filas y columnas). Ideal para la estructura general de una página, o una galería de tarjetas de tamaño uniforme.

.galeria {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 columnas iguales */
  gap: 16px;
}
.pagina {
  display: grid;
  grid-template-columns: 240px 1fr;  /* menú fijo + contenido flexible */
  grid-template-rows: auto 1fr auto; /* cabecera, cuerpo, pie */
  min-height: 100vh;
}

1fr significa "una fracción del espacio sobrante" — repeat(3, 1fr) crea tres columnas exactamente iguales sin calcular porcentajes a mano. Combinar una columna fija (240px) con una flexible (1fr) es el patrón típico de menú lateral + contenido.

Regla práctica: Flexbox para una fila o columna de cosas; Grid para la estructura general de la página o una cuadrícula de verdad.

05

Posicionamiento

La propiedad position saca un elemento del flujo normal de la página para colocarlo con coordenadas exactas (top, right, bottom, left). Es la base de cualquier diseño tipo cartel, donde un texto se superpone a una imagen de fondo en un punto exacto.

ValorComportamiento
staticPor defecto: flujo normal, top/left no hacen nada.
relativeSigue ocupando su hueco normal, pero se desplaza visualmente desde ahí, y se convierte en referencia para hijos absolute.
absoluteSe posiciona respecto al ancestro relative más cercano (o al documento, si no hay ninguno) — deja de ocupar espacio en el flujo.
fixedComo absolute, pero respecto a la ventana — se queda quieto al hacer scroll.
.cartel {
  position: relative; /* ancla para el texto de dentro */
  width: 800px;
  background: url("fondo.jpg") center/cover;
}
.cartel .titulo {
  position: absolute;
  top: 40px;
  left: 50%;
  transform: translateX(-50%); /* centra el texto exactamente */
}

El truco de left: 50%; transform: translateX(-50%); centra un elemento de ancho desconocido: primero lo mueve al 50% del padre, luego lo retrocede la mitad de su propio ancho.

06

Diseño responsive

Una página responsive se adapta a cualquier tamaño de pantalla. La herramienta principal son las media queries: bloques de CSS que solo se aplican si se cumple una condición sobre la ventana.

.menu {
  display: flex;
}

@media (max-width: 600px) {
  .menu {
    flex-direction: column; /* en pantallas pequeñas, apila el menú */
  }
}

Con Flexbox y Grid, muchas veces ni siquiera hace falta media queries: propiedades como flex-wrap: wrap o grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)) ya reparten el contenido solas según el espacio disponible.

Usa unidades relativas cuando tenga sentido: % o fr para anchos que dependen del contenedor, rem para tipografía (relativa al tamaño de fuente raíz, respeta si el usuario lo ha cambiado en su navegador), y reserva px para cosas que de verdad deben medir siempre lo mismo (un borde de 1px, por ejemplo).

07

Clonar una página con DevTools

Para reproducir una página existente con precisión (como pide el desafío de las páginas gemelas), las herramientas de desarrollador del navegador (F12 o clic derecho → Inspeccionar) son el mejor punto de partida.

  • Panel Elements/Inspector: selecciona cualquier elemento con el cursor y ve su HTML exacto.
  • Panel Styles: muestra todas las reglas CSS que afectan al elemento seleccionado, tachadas las que pierden la cascada — así se ve qué valor gana y por qué.
  • Computed: el valor final ya calculado de cada propiedad (color exacto en rgb(), tamaño de fuente en px…), aunque en el CSS original estuviera en otra unidad.
  • Selector de color (icono de pipeta): al hacer clic en cualquier muestra de color en el panel Styles, se puede copiar su valor exacto en hexadecimal.
Método recomendado para una réplica exacta

Ve sección por sección: inspecciona un bloque, anota sus medidas y colores exactos desde Computed, replícalo en tu propio archivo, y compara ambas páginas una al lado de la otra antes de seguir con el siguiente bloque. Cambiar el zoom del navegador a 100% en ambas pestañas evita comparaciones falsas por diferencias de escala.

Con HTML y CSS ya se puede maquetar cualquier página estática. El siguiente paso es hacerlo más rápido con un sistema de componentes ya hecho: Bootstrap 5.
