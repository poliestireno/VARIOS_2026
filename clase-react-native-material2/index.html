Bloque 1

JavaScript desde cero

Sesiones 1–4 · Semanas 1–2

Sin esto, React Native es sintaxis sin sentido. El objetivo no es dominar JS, es tener las manos suficientes para no tropezar constantemente cuando empiece React.

1

Fundamentos del lenguaje

Ejecutar código, guardar datos y tomar decisiones.

Contenido: variables (let, const), tipos de datos, operadores, condicionales (if/else), comparación (===).

Práctica: programa de consola sencillo (clasificador de edad / calculadora de IMC).

2

Funciones y bucles

Dejar de repetir código a mano.

Contenido: function y arrow functions, parámetros y retorno, for, while, scope básico.

Práctica: FizzBuzz o generador de tablas de multiplicar.

3

Arrays y objetos

Modelar colecciones de datos, la base de casi toda app real.

Contenido: arrays y sus métodos (map, filter, find, reduce), objetos y propiedades, destructuring, spread/rest.

Práctica: gestionar una lista de "alumnos" (array de objetos) con filtros y transformaciones.

4

JS moderno y asíncrono

Preparar el terreno justo para React: módulos y código que "espera".

Contenido: import/export, template literals, introducción a promesas y async/await con una llamada real a fetch.

Práctica: ejercicio integrador del bloque + primera petición a una API pública.

Bloque 2

TypeScript

Sesiones 5–6 · Semana 3

El proyecto de Expo que vais a crear viene en TypeScript por defecto, así que esta capa se aprende ahora, con el mismo JavaScript ya conocido, antes de mezclarla con componentes y JSX.

5

TypeScript: fundamentos

Añadir tipos al JavaScript que ya conocéis, y ver el error en el editor antes de ejecutar nada.

Contenido: tipos básicos (string, number, boolean, arrays), tipar funciones, type / interface, tipos unión y literales.

Práctica: volver a los ejercicios de las sesiones 1 y 3 (calculadora de IMC, lista de alumnos) y añadirles tipos.

6

TypeScript en la práctica

Lo que hace falta a diario: datos opcionales, datos que llegan de fuera, y un adelanto de cómo se tipan las props de un componente.

Contenido: propiedades opcionales y readonly, any frente a unknown, tipar la respuesta de un fetch, genéricos básicos.

Práctica: tipar la función fetch de la sesión 4 y escribir el primer type de props, sin JSX todavía.

Bloque 3

React

Sesiones 7–10 · Semanas 4–5

Todo en el navegador todavía — deliberadamente, y ya en TypeScript. Separar "cómo piensa React" de "cómo se ve en el móvil" evita mezclar dos curvas de aprendizaje a la vez.

7

Primeros componentes

La idea central de React: la interfaz es una función de los datos.

Contenido: JSX, componentes funcionales, props tipadas con type, renderizar listas con .map().

Práctica: tarjeta de perfil reutilizable que recibe props distintas.

8

Estado e interactividad

Que la pantalla reaccione a lo que hace el usuario.

Contenido: useState, manejadores de eventos, renderizado condicional.

Práctica: contador y lista de tareas básica.

9

Efectos y formularios

Sincronizar componentes con el exterior y capturar entradas.

Contenido: useEffect, formularios controlados, inputs, validación básica.

Práctica: formulario de registro con validación y feedback visual.

10

Composición y proyecto de repaso

Combinar componentes en una app pequeña y coherente.

Contenido: paso de props entre niveles, organización de componentes en archivos.

Práctica: mini proyecto integrador (lista de la compra: añadir, eliminar, marcar).

Bloque 4

React Native

Sesiones 11–18 · Semanas 6–9

Aquí entra el móvil de verdad. Progresión pensada para encadenar directamente con los ejemplos ya construidos en clase (el contador, Arcanoid, Pang, Black Jack, Brisca).

11

Del navegador al móvil

Entender qué cambia entre React web y React Native.

Contenido: Expo, Expo Go, estructura de un proyecto con Expo Router, View/Text frente a div/span.

Práctica: guía “Contador en Expo” ya preparada, paso a paso hasta verlo en el móvil.

12

Componentes visuales y estilos

Construir pantallas con los bloques básicos de RN.

Contenido: Image, Pressable, ScrollView, StyleSheet, Flexbox en RN (diferencias con CSS web).

Práctica: pantalla de perfil con imagen, textos y botones estilizados.

13

Listas y gestos

Mostrar colecciones de forma eficiente y capturar el dedo del usuario.

Contenido: FlatList, keyExtractor, PanResponder y gestos básicos.

Práctica: retomar el Arcanoid/Pang de clase y explicar el arrastre de la pala línea a línea.

14

Navegación

Pasar de una pantalla a apps de verdad, con varias.

Contenido: Expo Router, rutas por convención de archivos, rutas dinámicas, Stack y Tabs anidados.

Práctica: app de 3 pantallas navegables (lista → detalle → ajustes).

15

Entrada de usuario avanzada

Formularios e interacción compleja en móvil.

Contenido: TextInput, teclado, KeyboardAvoidingView, Modal.

Práctica: formulario de “nueva nota” o “nuevo contacto” dentro de un modal.

16

Conectar con el exterior

Consumir datos de una API real.

Contenido: fetch, useEffect con estados de carga/error, listas de datos remotos.

Práctica: app que consulta una API pública (clima, películas…) y muestra resultados.

17

Guardar datos

Que la app recuerde algo al cerrarla y reabrirla.

Contenido: AsyncStorage, leer y escribir datos localmente.

Práctica: añadir favoritos o historial persistente a la app de la sesión anterior.

18

Cierre de bloque: lógica de juego

Integrar estado complejo, condiciones y bucles de juego.

Contenido: repaso useState vs useRef para bucles de animación, máquinas de estado simples (como en Black Jack/Brisca).

Práctica: cada alumno amplía uno de los juegos de clase con una función nueva propia.

Bloque 5

Proyecto final

Sesiones 19–26 · Semanas 10–13

De aquí en adelante tú dejas de dar contenido nuevo y pasas a guiar: cada alumno o grupo construye su propia app de principio a fin.

19

Definición del proyecto

Pasar de idea a especificación realista.

Contenido: elección de idea, alcance para 7 sesiones, wireframes, lista de funcionalidades mínimas (MVP).

Práctica: entrega de propuesta de proyecto + wireframes de pantallas.

20

Arquitectura

Sentar las bases técnicas antes de programar a lo loco.

Contenido: estructura de carpetas con Expo Router, planificación de pantallas y componentes.

Práctica: esqueleto navegable del proyecto (pantallas vacías ya conectadas).

21

Desarrollo I — pantallas principales

Construir la funcionalidad core del proyecto.

Contenido: trabajo guiado individual, dudas, revisión de código en vivo.

Práctica: implementar 1–2 pantallas principales del proyecto propio.

22

Desarrollo II — interacción y estado

Completar la lógica de negocio de la app.

Contenido: gestión de estado entre pantallas, formularios, validaciones.

Práctica: continuar el desarrollo con seguimiento individual por mesas.

23

Datos y persistencia

Conectar el proyecto con datos reales o persistentes.

Contenido: API externa o AsyncStorage según el proyecto, manejo de errores y carga.

Práctica: integrar la fuente de datos elegida en el proyecto propio.

24

Estado global y pulido funcional

Resolver los dolores de cabeza de estado compartido entre pantallas.

Contenido: Context API (introducción), revisión de bugs, checklist funcional.

Práctica: refactor de estado compartido + corrección de errores pendientes.

25

Pulido visual y build

Dejar la app lista para enseñarla fuera del aula.

Contenido: estilos finales, icono/splash, introducción a EAS Build para generar una build de prueba.

Práctica: generar una build instalable del proyecto propio.

26

Demo day

Presentar y defender el trabajo de todo el curso.

Contenido: presentaciones en vivo desde el móvil de cada alumno o grupo.

Práctica: demo + feedback final del curso.

Los bloques 1, 2 y 3 son intencionadamente independientes del móvil — todo en el navegador, para no mezclar la curva de aprendizaje de JavaScript/TypeScript/React con la de React Native a la vez. El bloque 4 reutiliza directamente los ejemplos ya construidos en clase (contador, Arcanoid, Pang, Black Jack, Brisca) como progresión natural de dificultad, ya con Expo Router y TypeScript de serie.
