Guía de clase · práctica de la Sesión 18

Ahorcado en 4 fases

El clásico juego de adivinar una palabra, letra a letra — con una vuelta de tuerca: la palabra no la inventas tú, la pide la app a una API real de internet. Es el compañero perfecto del Arkanoid: mismo curso, mismo estilo de 4 fases, pero un patrón de estado completamente distinto.

React Native + Expo TypeScript fetch + async/await useState por turno ~35 min
← Volver a la Sesión 18

Antes de empezar

  • Node.js, VS Code y un proyecto de Expo funcionando. Si te falta cualquiera de los dos, empieza por la guía “Contador en Expo”.
  • Conexión a internet mientras pruebas la app: cada partida pide una palabra nueva a una API pública. No hace falta ninguna clave (“API key”) ni registro.
  • Haber visto useState (Sesión 8) y fetch/async‑await (Sesión 16, “Conectar con el exterior”). Si la Sesión 16 todavía te queda lejos, este es un buen sitio para repasarlo con un caso real y pequeño.

La API que vamos a usar

random-word-api.herokuapp.com es una API pública y gratuita de palabras aleatorias. Con el parámetro lang=es devuelve palabras en español, como un array de un solo elemento:

$ curl "https://random-word-api.herokuapp.com/word?lang=es"
["cuenca"]
Los datos de internet llegan sucios — y esto no es una excepción

Esta API no está pensada para juegos de mesa: de vez en cuando devuelve palabras con tildes, en mayúscula, en otro idioma, o incluso algún símbolo suelto. En vez de asumir que el dato viene limpio, la Fase 1 incluye una función que valida cada palabra y pide otra si no sirve — una comprobación que en el mundo real harías con cualquier API que no controlas tú.

Qué vas a construir

  • Fase 1 · Pedir una palabra a la API — fetch, estado de carga, y una función que limpia y valida lo que llega.
  • Fase 2 · Revelar letras — la palabra se oculta con guiones; un teclado en pantalla (A-Z) va revelando las letras correctas.
  • Fase 3 · Fallos y derrota — cada letra que falla cuenta; al llegar a 6 fallos, se acaba la partida y se revela la palabra.
  • Fase 4 · Ganar y jugar de nuevo — victoria al completar la palabra, y un botón que pide otra palabra distinta a la API para volver a jugar.
El otro patrón de la Sesión 18

Fíjate en que en ningún momento aparece un setInterval ni un useRef para el estado del juego: cada cambio —revelar una letra, sumar un fallo, ganar— ocurre porque el jugador tocó algo, nunca solo. Es el “Patrón B” de la Sesión 18, el mismo que Black Jack o Brisca: useState normal, disparado por onPress, sin bucle de ningún tipo. Compáralo con el Arkanoid (Patrón A) cuando lo veas.

Fase 1

Pedir una palabra a la API

Objetivo: al entrar a la pantalla, pedir una palabra válida a la API y mostrarla. Sin juego todavía — solo fetch, carga y validación.

1

Limpiar lo que llega de la API

La API a veces devuelve palabras con tildes o símbolos. quitarAcentos usa un truco de Unicode: normalize('NFD') separa cada letra acentuada en dos piezas —la letra base y una “marca de acento” aparte—, y luego filtramos esas marcas por su código.

extracto
function quitarAcentos(texto: string): string {
  return texto
    .normalize('NFD')
    .split('')
    .filter((caracter) => {
      const codigo = caracter.codePointAt(0) ?? 0;
      const esMarcaDeAcento = codigo >= 0x0300 && codigo <= 0x036f;
      return !esMarcaDeAcento;
    })
    .join('');
}

Con la palabra ya sin tildes, limpiarPalabra la pasa a mayúsculas y comprueba con una expresión regular que sean solo letras A-Z, de 4 a 10 de longitud. Si no cumple, devuelve null y la descartamos.

extracto
function limpiarPalabra(bruta: string): string | null {
  const mayusculas = quitarAcentos(bruta).toUpperCase();
  if (!/^[A-Z]{4,10}$/.test(mayusculas)) return null;
  return mayusculas;
}
2

Pedir palabras hasta que llegue una válida

extracto
async function pedirPalabra(): Promise<string> {
  while (true) {
    const respuesta = await fetch(URL_API);
    const datos: string[] = await respuesta.json(); // ej: ["cuenca"]
    const limpia = limpiarPalabra(datos[0]);
    if (limpia) return limpia;
    // si no era válida, el bucle vuelve a pedir otra
  }
}

await fetch(...) espera a que llegue la respuesta antes de seguir; await respuesta.json() espera a que ese cuerpo de la respuesta se convierta en un array de JavaScript. El while (true) es intencionado: la función no termina hasta que consigue una palabra que pasa la validación —normalmente la primera ya sirve, pero el código no lo da por hecho.

3

Pedirla al entrar a la pantalla

extracto
const [palabra, setPalabra] = useState<string | null>(null);
const [cargando, setCargando] = useState(true);

useEffect(() => {
  pedirPalabra().then((p) => {
    setPalabra(p);
    setCargando(false);
  });
}, []);

El array de dependencias vacío ([]) hace que este useEffect se ejecute una sola vez, al montar el componente —justo lo que hace falta para pedir la palabra inicial. Mientras cargando es true, mostramos un ActivityIndicator en vez de la palabra.

Ver fase1.tsx completo
src/app/fase1.tsx 
import { useEffect, useState } from 'react';
import { ActivityIndicator, StyleSheet, Text, View } from 'react-native';

// ---------------------------------------------------------------------
// FASE 1: solo pedir una palabra a una API real de internet y mostrarla
// en pantalla. Todavía no hay juego: el objetivo es dominar el fetch,
// el estado de "cargando", y limpiar un dato que llega sucio.
// ---------------------------------------------------------------------

// API pública y gratuita de palabras aleatorias, con soporte de español
// mediante el parámetro lang=es. Devuelve un array con una palabra: ["casa"]
const URL_API = 'https://random-word-api.herokuapp.com/word?lang=es';

// Quita las tildes de una palabra: "á" -> "a", "ó" -> "o"...
// normalize('NFD') separa cada letra acentuada en dos piezas: la letra
// base ("a") y un carácter de marca de acento aparte (código Unicode
// entre 0x0300 y 0x036F). Filtrando esos códigos, solo queda la letra base.
function quitarAcentos(texto: string): string {
  return texto
    .normalize('NFD')
    .split('')
    .filter((caracter) => {
      const codigo = caracter.codePointAt(0) ?? 0;
      const esMarcaDeAcento = codigo >= 0x0300 && codigo <= 0x036f;
      return !esMarcaDeAcento;
    })
    .join('');
}

// Esta API no está pensada para juegos: a veces devuelve palabras con
// tildes, en mayúscula, en otro idioma o incluso símbolos sueltos. Esta
// función se queda solo con las que nos sirven: solo letras A-Z (sin
// tildes ni Ñ, para mantener el juego "muy sencillo"), de 4 a 10 letras.
function limpiarPalabra(bruta: string): string | null {
  const mayusculas = quitarAcentos(bruta).toUpperCase();

  if (!/^[A-Z]{4,10}$/.test(mayusculas)) {
    return null; // no nos sirve: la descartamos
  }
  return mayusculas;
}

// Pide palabras a la API, una tras otra, hasta que llega una válida.
async function pedirPalabra(): Promise<string> {
  while (true) {
    const respuesta = await fetch(URL_API);
    const datos: string[] = await respuesta.json(); // ej: ["cuenca"]
    const limpia = limpiarPalabra(datos[0]);
    if (limpia) {
      return limpia;
    }
    // Si no era válida, el bucle vuelve a empezar y pide otra.
  }
}

export default function Fase1() {
  const [palabra, setPalabra] = useState<string | null>(null);
  const [cargando, setCargando] = useState(true);

  // useEffect con array vacío [] : se ejecuta una sola vez, al entrar
  // a la pantalla. Justo lo que necesitamos para pedir la palabra inicial.
  useEffect(() => {
    pedirPalabra().then((p) => {
      setPalabra(p);
      setCargando(false);
    });
  }, []);

  return (
    <View style={styles.pantalla}>
      <Text style={styles.titulo}>Fase 1 · Pedir una palabra a la API</Text>

      {cargando ? (
        <ActivityIndicator size="large" color="#2563eb" />
      ) : (
        <Text style={styles.palabra}>{palabra}</Text>
      )}

      <Text style={styles.ayuda}>
        {cargando ? 'Pidiendo palabra...' : 'Palabra recibida y validada (solo A-Z, 4 a 10 letras)'}
      </Text>
    </View>
  );
}

const styles = StyleSheet.create({
  pantalla: { flex: 1, backgroundColor: '#fff', alignItems: 'center', justifyContent: 'center', gap: 16, padding: 24 },
  titulo: { fontSize: 18, fontWeight: 'bold', textAlign: 'center' },
  palabra: { fontSize: 32, fontWeight: 'bold', letterSpacing: 4, color: '#2563eb' },
  ayuda: { fontSize: 13, color: '#888' },
});

Fase 2

Revelar letras

Objetivo: ocultar la palabra con guiones y revelar las letras correctas al tocarlas en un teclado en pantalla.

1

De la palabra real a lo que se ve en pantalla

extracto
function mostrarPalabra(palabra: string, letrasUsadas: string[]): string {
  return palabra
    .split('')
    .map((letra) => (letrasUsadas.includes(letra) ? letra : '_'))
    .join(' ');
}

letrasUsadas es un useState<string[]>([]): el array de letras que el jugador ya ha pulsado. Por cada letra de la palabra, si ya está en ese array se muestra tal cual; si no, se sustituye por '_'. El resultado para CASA con letrasUsadas = ['A'] sería "_ A _ A".

2

Un teclado que se dibuja solo

extracto
const ALFABETO = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ'.split('');

// dentro del JSX:
<View style={styles.teclado}>
  {ALFABETO.map((letra) => {
    const yaUsada = letrasUsadas.includes(letra);
    return (
      <Pressable
        key={letra}
        style={[styles.tecla, yaUsada && styles.teclaUsada]}
        onPress={() => marcarLetra(letra)}
        disabled={yaUsada}
      >
        <Text style={styles.textoTecla}>{letra}</Text>
      </Pressable>
    );
  })}
</View>

26 botones generados con .map(), no escritos a mano. El estilo teclado usa flexWrap: 'wrap' (visto en el mini Space Invaders y en Adivina el número) para que, cuando no quepan en una fila, salten solas a la siguiente. disabled={'{yaUsada}'} evita marcar la misma letra dos veces.

Fase 3

Fallos y derrota

Objetivo: las letras que no están en la palabra cuentan como fallo. A los 6 fallos, se pierde y se revela la palabra completa.

1

Contar solo los fallos de verdad

extracto
function marcarLetra(letra: string) {
  if (estado !== 'jugando' || letrasUsadas.includes(letra) || !palabra) return;

  setLetrasUsadas([...letrasUsadas, letra]);

  if (!palabra.includes(letra)) {
    const nuevosFallos = fallos + 1;
    setFallos(nuevosFallos);
    if (nuevosFallos >= MAX_FALLOS) {
      setEstado('perdido');
    }
  }
}

La primera línea es una guarda con tres condiciones: si la partida ya terminó, si esa letra ya se pulsó antes, o si todavía no hay palabra cargada, no hacemos nada. nuevosFallos se calcula en una variable aparte (en vez de leer fallos otra vez después de setFallos) porque, como ya viste con useState, el valor de fallos dentro de esta misma función no cambia hasta el siguiente render.

2

Visualizar los fallos sin dibujar un muñeco

Para mantenerlo “muy sencillo”, en vez del dibujo tradicional del ahorcado usamos 6 círculos que se van rellenando de rojo:

extracto
<View style={styles.filaFallos}>
  {Array.from({ length: MAX_FALLOS }).map((_, indice) => (
    <View key={indice} style={[styles.bolaFallo, indice < fallos && styles.bolaFalloActiva]} />
  ))}
</View>

Array.from({'{ length: 6 }'}) crea un array de 6 huecos vacíos, solo para poder recorrerlo con .map() —un truco habitual cuando quieres repetir algo un número fijo de veces sin tener datos reales que recorrer. Cada círculo se pinta de rojo si su posición es menor que fallos.

  return mayusculas;

Fase 4

Ganar y jugar de nuevo

Objetivo: detectar la victoria, y un botón que vuelve a pedir una palabra a la API para empezar otra partida.

1

¿Están ya todas las letras?

extracto
function estaCompleta(palabra: string, letrasUsadas: string[]): boolean {
  const letrasUnicas = Array.from(new Set(palabra.split('')));
  return letrasUnicas.every((letra) => letrasUsadas.includes(letra));
}

new Set(...) quita las letras repetidas —en "ARBOL" ya no importaría, pero en una palabra como "ELEFANTE" evita exigir que 'E' se marque tres veces. .every(...) devuelve true solo si todas esas letras únicas están ya en letrasUsadas.

2

Jugar de nuevo: repetir la Fase 1, pero como función

extracto
function jugarDeNuevo() {
  setCargando(true);
  setEstado('jugando');
  setLetrasUsadas([]);
  setFallos(0);
  pedirPalabra().then((p) => {
    setPalabra(p);
    setCargando(false);
  });
}

Es literalmente el mismo pedirPalabra() de la Fase 1, solo que ahora se llama desde un botón (onPress) en vez de desde un useEffect al montar la pantalla. Antes de pedir la nueva palabra, se resetean letrasUsadas, fallos y estado —si no, la siguiente partida empezaría ya con fallos del intento anterior.

src/app/fase4.tsx 
import { useEffect, useState } from 'react';
import { ActivityIndicator, Pressable, StyleSheet, Text, View } from 'react-native';

// ---------------------------------------------------------------------
// FASE 4: se añade la victoria (revelar todas las letras) y el botón
// "Jugar de nuevo", que vuelve a pedir una palabra distinta a la API
// y reinicia fallos y letras usadas.
// ---------------------------------------------------------------------

const URL_API = 'https://random-word-api.herokuapp.com/word?lang=es';
const ALFABETO = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ'.split('');
const MAX_FALLOS = 6;

type EstadoJuego = 'jugando' | 'perdido' | 'ganado';

function quitarAcentos(texto: string): string {
  return texto
    .normalize('NFD')
    .split('')
    .filter((caracter) => {
      const codigo = caracter.codePointAt(0) ?? 0;
      return !(codigo >= 0x0300 && codigo <= 0x036f);
    })
    .join('');
}

function limpiarPalabra(bruta: string): string | null {
  const mayusculas = quitarAcentos(bruta).toUpperCase();
  if (!/^[A-Z]{4,10}$/.test(mayusculas)) return null;
  return mayusculas;
}

async function pedirPalabra(): Promise<string> {
  while (true) {
    const respuesta = await fetch(URL_API);
    const datos: string[] = await respuesta.json();
    const limpia = limpiarPalabra(datos[0]);
    if (limpia) return limpia;
  }
}

function mostrarPalabra(palabra: string, letrasUsadas: string[]): string {
  return palabra
    .split('')
    .map((letra) => (letrasUsadas.includes(letra) ? letra : '_'))
    .join(' ');
}

// Todas las letras distintas de la palabra ya están en letrasUsadas.
function estaCompleta(palabra: string, letrasUsadas: string[]): boolean {
  const letrasUnicas = Array.from(new Set(palabra.split('')));
  return letrasUnicas.every((letra) => letrasUsadas.includes(letra));
}

export default function Fase4() {
  const [palabra, setPalabra] = useState<string | null>(null);
  const [cargando, setCargando] = useState(true);
  const [letrasUsadas, setLetrasUsadas] = useState<string[]>([]);
  const [fallos, setFallos] = useState(0);
  const [estado, setEstado] = useState<EstadoJuego>('jugando');

  useEffect(() => {
    pedirPalabra().then((p) => {
      setPalabra(p);
      setCargando(false);
    });
  }, []);

  function marcarLetra(letra: string) {
    if (estado !== 'jugando' || letrasUsadas.includes(letra) || !palabra) return;

    const nuevasLetras = [...letrasUsadas, letra];
    setLetrasUsadas(nuevasLetras);

    if (!palabra.includes(letra)) {
      const nuevosFallos = fallos + 1;
      setFallos(nuevosFallos);
      if (nuevosFallos >= MAX_FALLOS) {
        setEstado('perdido');
      }
    } else if (estaCompleta(palabra, nuevasLetras)) {
      setEstado('ganado');
    }
  }

  // Pide una palabra nueva y reinicia todo lo demás.
  function jugarDeNuevo() {
    setCargando(true);
    setEstado('jugando');
    setLetrasUsadas([]);
    setFallos(0);
    pedirPalabra().then((p) => {
      setPalabra(p);
      setCargando(false);
    });
  }

  if (cargando || !palabra) {
    return (
      <View style={styles.pantalla}>
        <ActivityIndicator size="large" color="#2563eb" />
      </View>
    );
  }

  return (
    <View style={styles.pantalla}>
      <Text style={styles.titulo}>Fase 4 · Ganar y jugar de nuevo</Text>

      <View style={styles.filaFallos}>
        {Array.from({ length: MAX_FALLOS }).map((_, indice) => (
          <View key={indice} style={[styles.bolaFallo, indice < fallos && styles.bolaFalloActiva]} />
        ))}
      </View>
      <Text style={styles.contadorFallos}>
        Fallos: {fallos}/{MAX_FALLOS}
      </Text>

      <Text style={styles.palabraOculta}>
        {estado === 'perdido' ? palabra : mostrarPalabra(palabra, letrasUsadas)}
      </Text>

      {estado === 'perdido' && <Text style={styles.mensajePerdido}>Perdiste 💀</Text>}
      {estado === 'ganado' && <Text style={styles.mensajeGanado}>¡Ganaste! 🎉</Text>}

      {estado === 'jugando' ? (
        <View style={styles.teclado}>
          {ALFABETO.map((letra) => {
            const yaUsada = letrasUsadas.includes(letra);
            return (
              <Pressable
                key={letra}
                style={[styles.tecla, yaUsada && styles.teclaUsada]}
                onPress={() => marcarLetra(letra)}
                disabled={yaUsada}
              >
                <Text style={styles.textoTecla}>{letra}</Text>
              </Pressable>
            );
          })}
        </View>
      ) : (
        <Pressable style={styles.boton} onPress={jugarDeNuevo}>
          <Text style={styles.textoBoton}>Jugar de nuevo</Text>
        </Pressable>
      )}
    </View>
  );
}

const styles = StyleSheet.create({
  pantalla: { flex: 1, backgroundColor: '#fff', alignItems: 'center', justifyContent: 'center', gap: 14, padding: 24 },
  titulo: { fontSize: 18, fontWeight: 'bold' },
  filaFallos: { flexDirection: 'row', gap: 8 },
  bolaFallo: { width: 18, height: 18, borderRadius: 9, borderWidth: 2, borderColor: '#dc2626' },
  bolaFalloActiva: { backgroundColor: '#dc2626' },
  contadorFallos: { fontSize: 13, color: '#888' },
  palabraOculta: { fontSize: 30, fontWeight: 'bold', letterSpacing: 4 },
  mensajePerdido: { fontSize: 20, fontWeight: 'bold', color: '#dc2626' },
  mensajeGanado: { fontSize: 20, fontWeight: 'bold', color: '#16a34a' },
  teclado: {
    flexDirection: 'row',
    flexWrap: 'wrap',
    justifyContent: 'center',
    gap: 6,
    maxWidth: 320,
  },
  tecla: {
    width: 34,
    height: 34,
    borderRadius: 6,
    backgroundColor: '#2563eb',
    alignItems: 'center',
    justifyContent: 'center',
  },
  teclaUsada: { backgroundColor: '#cbd5e1' },
  textoTecla: { color: '#fff', fontWeight: 'bold' },
  boton: { backgroundColor: '#2563eb', paddingVertical: 12, paddingHorizontal: 24, borderRadius: 8 },
  textoBoton: { color: '#fff', fontSize: 16, fontWeight: '600' },
});
Deberías ver esto

Completa la palabra sin llegar a 6 fallos y verás “¡Ganaste!” en vez de “Perdiste”. En cualquiera de los dos casos, el teclado desaparece y aparece “Jugar de nuevo” —tócalo y, tras un instante pidiendo la nueva palabra, empieza otra partida distinta.

Retos extra

Añade una pista: un botón que revela una letra al azar de las que faltan, a cambio de sumar un fallo directamente.

Muestra una categoría junto a la palabra pidiendo, además, una definición a otra API de diccionario (en inglés; en español tendrías que traducir la palabra primero).

Guarda un contador de victorias con AsyncStorage (Sesión 17) para que sobreviva a cerrar y volver a abrir la app.

Si algo falla

La app se queda cargando para siempre

Comprueba tu conexión a internet, o que la URL no tenga ningún espacio o carácter de más. Si la API tarda mucho, el ActivityIndicator puede quedarse girando varios segundos —es normal, es una API pública compartida, no un servidor propio.

Salen palabras rarísimas o con mayúsculas raras

Es justo lo que limpiarPalabra intenta evitar: si aun así ves algo extraño, revisa que la expresión regular sea exactamente /^[A-Z]{4,10}$/ y que se aplique después de quitarAcentos(...).toUpperCase(), no antes.

Nunca se pierde ni se gana

Revisa que marcarLetra compare exactamente con el mismo formato en el que guardaste palabra (mayúsculas) y en el que generas ALFABETO (también mayúsculas). Si uno está en minúsculas y el otro no, .includes(...) nunca encontrará coincidencias.

Vuelve a la Sesión 18 y compara: en el Ahorcado, cada setState es la reacción directa a un toque; en el Arkanoid, la mayoría de cambios los dispara un setInterval que nadie tocó. Esa diferencia es todo el contenido de la sesión, ahora visto en código de verdad.
