Ejemplo · Piedra, papel o tijera

Piedra, papel o tijera en 4 fases

El clásico juego contra la máquina, construido paso a paso: primero elegir y mostrar, luego decidir quién gana, después un marcador que no se pierde entre rondas, y por último una partida completa al mejor de 3. Cada fase es un archivo independiente y funcionando, igual que el Ahorcado y el Arkanoid.

React Native + Expo TypeScript 4 fases

← Volver al índice del curso

Necesitas Node.js, VS Code y un proyecto de Expo funcionando. Si te falta alguno, empieza por la guía “Contador en Expo” — los pasos de creación son idénticos, solo cambia el nombre del proyecto (aquí, piedrapapeltijera). Cada fase de abajo es un archivo distinto dentro de app/ (fase1.tsx, fase2.tsx…), enlazados desde un menú en index.tsx.

Fase 1 · Elegir y mostrar

Elegir piedra, papel o tijera y ver qué responde la máquina. Todavía no hay ganador: el objetivo es solo guardar las dos elecciones en estado y mostrarlas en pantalla.

  • useState para guardar la elección del jugador y la de la máquina.
  • Una función auxiliar que elige al azar entre las tres opciones.
  • Un emoji por opción en vez de solo texto, para que se vea como un juego de verdad.
app/fase1.tsx 
import { useState } from 'react';
import { Pressable, StyleSheet, Text, View } from 'react-native';

// ---------------------------------------------------------------------
// FASE 1: elegir piedra, papel o tijera y ver qué elige la máquina.
// Todavía no hay ganador: el objetivo es solo guardar dos elecciones
// en estado (la del jugador y la de la máquina, al azar) y mostrarlas.
// ---------------------------------------------------------------------

type Opcion = 'piedra' | 'papel' | 'tijera';

const OPCIONES: Opcion[] = ['piedra', 'papel', 'tijera'];

// Un emoji por opción, para no mostrar solo texto.
const EMOJI: Record<Opcion, string> = {
  piedra: '🪨',
  papel: '📄',
  tijera: '✂️',
};

// Elige una opción al azar entre las tres posibles.
function elegirAlAzar(): Opcion {
  const indice = Math.floor(Math.random() * OPCIONES.length);
  return OPCIONES[indice];
}

export default function Fase1() {
  const [eleccionJugador, setEleccionJugador] = useState<Opcion | null>(null);
  const [eleccionMaquina, setEleccionMaquina] = useState<Opcion | null>(null);

  function jugar(opcion: Opcion) {
    setEleccionJugador(opcion);
    setEleccionMaquina(elegirAlAzar());
  }

  return (
    <View style={styles.pantalla}>
      <Text style={styles.titulo}>Fase 1 · Elegir y mostrar</Text>

      <View style={styles.marcador}>
        <View style={styles.lado}>
          <Text style={styles.etiqueta}>Tú</Text>
          <Text style={styles.emojiGrande}>{eleccionJugador ? EMOJI[eleccionJugador] : '❔'}</Text>
        </View>
        <Text style={styles.vs}>VS</Text>
        <View style={styles.lado}>
          <Text style={styles.etiqueta}>Máquina</Text>
          <Text style={styles.emojiGrande}>{eleccionMaquina ? EMOJI[eleccionMaquina] : '❔'}</Text>
        </View>
      </View>

      <View style={styles.botones}>
        {OPCIONES.map((opcion) => (
          <Pressable key={opcion} style={styles.boton} onPress={() => jugar(opcion)}>
            <Text style={styles.emojiBoton}>{EMOJI[opcion]}</Text>
          </Pressable>
        ))}
      </View>
    </View>
  );
}

Fase 2 · Quién gana

Se añade la lógica que decide el resultado de la ronda: piedra vence a tijera, tijera vence a papel, papel vence a piedra; si ambos eligen lo mismo, es empate.

  • Un objeto GANA_A que guarda las reglas del juego, en vez de encadenar if/else.
  • Una función determinarGanador() que se puede probar aparte del componente.
  • Un texto de resultado distinto según quién ganó la ronda.
app/fase2.tsx 
import { useState } from 'react';
import { Pressable, StyleSheet, Text, View } from 'react-native';

// ---------------------------------------------------------------------
// FASE 2: ya se decide quién gana la ronda. Piedra vence a tijera,
// tijera vence a papel, papel vence a piedra; si ambos eligen lo
// mismo, es empate. Todavía no se guarda un marcador entre rondas.
// ---------------------------------------------------------------------

type Opcion = 'piedra' | 'papel' | 'tijera';
type Resultado = 'jugador' | 'maquina' | 'empate';

const OPCIONES: Opcion[] = ['piedra', 'papel', 'tijera'];

const EMOJI: Record<Opcion, string> = {
  piedra: '🪨',
  papel: '📄',
  tijera: '✂️',
};

// Qué opción vence a cuál: la clave gana a su valor.
const GANA_A: Record<Opcion, Opcion> = {
  piedra: 'tijera',
  tijera: 'papel',
  papel: 'piedra',
};

function elegirAlAzar(): Opcion {
  const indice = Math.floor(Math.random() * OPCIONES.length);
  return OPCIONES[indice];
}

// Compara las dos elecciones y decide quién gana la ronda.
function determinarGanador(jugador: Opcion, maquina: Opcion): Resultado {
  if (jugador === maquina) return 'empate';
  return GANA_A[jugador] === maquina ? 'jugador' : 'maquina';
}

const TEXTO_RESULTADO: Record<Resultado, string> = {
  jugador: 'Ganaste 🎉',
  maquina: 'Perdiste 💀',
  empate: 'Empate 🤝',
};

export default function Fase2() {
  const [eleccionJugador, setEleccionJugador] = useState<Opcion | null>(null);
  const [eleccionMaquina, setEleccionMaquina] = useState<Opcion | null>(null);
  const [resultado, setResultado] = useState<Resultado | null>(null);

  function jugar(opcion: Opcion) {
    const maquina = elegirAlAzar();
    setEleccionJugador(opcion);
    setEleccionMaquina(maquina);
    setResultado(determinarGanador(opcion, maquina));
  }

  return (
    <View style={styles.pantalla}>
      <Text style={styles.titulo}>Fase 2 · Quién gana</Text>

      <View style={styles.marcador}>
        <View style={styles.lado}>
          <Text style={styles.etiqueta}>Tú</Text>
          <Text style={styles.emojiGrande}>{eleccionJugador ? EMOJI[eleccionJugador] : '❔'}</Text>
        </View>
        <Text style={styles.vs}>VS</Text>
        <View style={styles.lado}>
          <Text style={styles.etiqueta}>Máquina</Text>
          <Text style={styles.emojiGrande}>{eleccionMaquina ? EMOJI[eleccionMaquina] : '❔'}</Text>
        </View>
      </View>

      <Text style={styles.resultado}>{resultado ? TEXTO_RESULTADO[resultado] : ' '}</Text>

      <View style={styles.botones}>
        {OPCIONES.map((opcion) => (
          <Pressable key={opcion} style={styles.boton} onPress={() => jugar(opcion)}>
            <Text style={styles.emojiBoton}>{EMOJI[opcion]}</Text>
          </Pressable>
        ))}
      </View>
    </View>
  );
}

  titulo: { fontSize: 18, fontWeight: 'bold' },

Fase 3 · Marcador

El resultado de cada ronda ya no se pierde: se suma a un marcador de victorias, derrotas y empates que se mantiene mientras se siguen jugando rondas, con un botón para reiniciarlo.

  • Tres estados nuevos (victorias, derrotas, empates) que no se resetean al jugar.
  • Sumar al contador correcto según el resultado de la ronda.
  • Un botón de texto para volver a poner el marcador a cero.
app/fase3.tsx 
import { useState } from 'react';
import { Pressable, StyleSheet, Text, View } from 'react-native';

// ---------------------------------------------------------------------
// FASE 3: se añade un marcador que se mantiene entre rondas. Cada vez
// que se juega, se suma un punto a "victorias", "derrotas" o
// "empates" según corresponda, y un botón permite reiniciarlo.
// ---------------------------------------------------------------------

type Opcion = 'piedra' | 'papel' | 'tijera';
type Resultado = 'jugador' | 'maquina' | 'empate';

const OPCIONES: Opcion[] = ['piedra', 'papel', 'tijera'];

const EMOJI: Record<Opcion, string> = {
  piedra: '🪨',
  papel: '📄',

export default function Fase3() {
  const [eleccionJugador, setEleccionJugador] = useState<Opcion | null>(null);

  const [resultado, setResultado] = useState<Resultado | null>(null);

  // Marcador acumulado: no se reinicia al jugar una nueva ronda.
  const [victorias, setVictorias] = useState(0);
  const [derrotas, setDerrotas] = useState(0);
  const [empates, setEmpates] = useState(0);

    setDerrotas(0);
    setEmpates(0);

    setEleccionMaquina(null);

        <View style={styles.lado}>
          <Text style={styles.etiqueta}>Tú</Text>

            <Text style={styles.emojiBoton}>{EMOJI[opcion]}</Text>

Fase 4 · Mejor de 3

La partida ya tiene un final: gana quien llegue antes a 2 rondas ganadas. Al terminar, los botones de jugar se sustituyen por un botón “Jugar de nuevo” que resetea la partida completa.

  • Una constante RONDAS_PARA_GANAR para no tener el número “2” suelto por el código.
  • Un estado estadoPartida ('jugando' | 'ganada' | 'perdida') que decide qué se muestra.
  • jugarDeNuevo() reinicia marcador y estado, igual que en el Ahorcado.
app/fase4.tsx 
import { useState } from 'react';
import { Pressable, StyleSheet, Text, View } from 'react-native';

// ---------------------------------------------------------------------
// FASE 4: la partida se juega "al mejor de 3": el primero que llega a
// 2 rondas ganadas se lleva la partida. Al terminar, los botones de
// jugar se cambian por un botón "Jugar de nuevo" que resetea todo.
// ---------------------------------------------------------------------

type Opcion = 'piedra' | 'papel' | 'tijera';
type Resultado = 'jugador' | 'maquina' | 'empate';
type EstadoPartida = 'jugando' | 'ganada' | 'perdida';

const OPCIONES: Opcion[] = ['piedra', 'papel', 'tijera'];
const RONDAS_PARA_GANAR = 2;

const EMOJI: Record<Opcion, string> = {
  piedra: '🪨',
  papel: '📄',
  tijera: '✂️',
};

const GANA_A: Record<Opcion, Opcion> = {
  piedra: 'tijera',
  tijera: 'papel',
  papel: 'piedra',
};

function elegirAlAzar(): Opcion {
  const indice = Math.floor(Math.random() * OPCIONES.length);
  return OPCIONES[indice];
}

function determinarGanador(jugador: Opcion, maquina: Opcion): Resultado {
  if (jugador === maquina) return 'empate';
  return GANA_A[jugador] === maquina ? 'jugador' : 'maquina';
}

const TEXTO_RESULTADO: Record<Resultado, string> = {
  jugador: 'Ganaste la ronda 🎉',
  maquina: 'Perdiste la ronda 💀',
  empate: 'Empate 🤝',
};

export default function Fase4() {
  const [eleccionJugador, setEleccionJugador] = useState<Opcion | null>(null);
  const [eleccionMaquina, setEleccionMaquina] = useState<Opcion | null>(null);
  const [resultado, setResultado] = useState<Resultado | null>(null);

  const [victorias, setVictorias] = useState(0);
  const [derrotas, setDerrotas] = useState(0);
  const [estadoPartida, setEstadoPartida] = useState<EstadoPartida>('jugando');

  function jugar(opcion: Opcion) {
    if (estadoPartida !== 'jugando') return;

    const maquina = elegirAlAzar();
    const nuevoResultado = determinarGanador(opcion, maquina);

    setEleccionJugador(opcion);
    setEleccionMaquina(maquina);
    setResultado(nuevoResultado);

    if (nuevoResultado === 'jugador') {
      const nuevasVictorias = victorias + 1;
      setVictorias(nuevasVictorias);
      if (nuevasVictorias >= RONDAS_PARA_GANAR) setEstadoPartida('ganada');
    } else if (nuevoResultado === 'maquina') {
      const nuevasDerrotas = derrotas + 1;
      setDerrotas(nuevasDerrotas);
      if (nuevasDerrotas >= RONDAS_PARA_GANAR) setEstadoPartida('perdida');
    }
  }

  function jugarDeNuevo() {
    setVictorias(0);
    setDerrotas(0);
    setEstadoPartida('jugando');
    setEleccionJugador(null);
    setEleccionMaquina(null);
    setResultado(null);
  }

  return (
    <View style={styles.pantalla}>
      <Text style={styles.titulo}>Fase 4 · Mejor de 3</Text>

      <View style={styles.filaMarcador}>
        <Text style={styles.puntoVictoria}>Tú {victorias}</Text>
        <Text style={styles.puntoDerrota}>Máquina {derrotas}</Text>
      </View>

      <View style={styles.marcador}>
        <View style={styles.lado}>
          <Text style={styles.etiqueta}>Tú</Text>
          <Text style={styles.emojiGrande}>{eleccionJugador ? EMOJI[eleccionJugador] : '❔'}</Text>
        </View>
        <Text style={styles.vs}>VS</Text>
        <View style={styles.lado}>
          <Text style={styles.etiqueta}>Máquina</Text>
          <Text style={styles.emojiGrande}>{eleccionMaquina ? EMOJI[eleccionMaquina] : '❔'}</Text>
        </View>
      </View>

      {estadoPartida === 'jugando' && (
        <Text style={styles.resultado}>{resultado ? TEXTO_RESULTADO[resultado] : ' '}</Text>
      )}
      {estadoPartida === 'ganada' && <Text style={styles.mensajeGanado}>¡Ganaste la partida! 🏆</Text>}
      {estadoPartida === 'perdida' && <Text style={styles.mensajePerdido}>Perdiste la partida 💀</Text>}

      {estadoPartida === 'jugando' ? (
        <View style={styles.botones}>
          {OPCIONES.map((opcion) => (
            <Pressable key={opcion} style={styles.boton} onPress={() => jugar(opcion)}>
              <Text style={styles.emojiBoton}>{EMOJI[opcion]}</Text>
            </Pressable>
          ))}
        </View>
      ) : (
        <Pressable style={styles.botonJugarDeNuevo} onPress={jugarDeNuevo}>
          <Text style={styles.textoBoton}>Jugar de nuevo</Text>
        </Pressable>
      )}
    </View>
  );
}

const styles = StyleSheet.create({
  pantalla: { flex: 1, backgroundColor: '#fff', alignItems: 'center', justifyContent: 'center', gap: 18, padding: 24 },
  titulo: { fontSize: 18, fontWeight: 'bold' },
  filaMarcador: { flexDirection: 'row', gap: 16 },
  puntoVictoria: { fontSize: 14, fontWeight: '600', color: '#16a34a' },
  puntoDerrota: { fontSize: 14, fontWeight: '600', color: '#dc2626' },
  marcador: { flexDirection: 'row', alignItems: 'center', gap: 20 },
  lado: { alignItems: 'center', gap: 6 },
  etiqueta: { fontSize: 13, color: '#888' },
  emojiGrande: { fontSize: 56 },
  vs: { fontSize: 16, fontWeight: 'bold', color: '#888' },
  resultado: { fontSize: 20, fontWeight: 'bold', minHeight: 26 },
  mensajeGanado: { fontSize: 20, fontWeight: 'bold', color: '#16a34a' },
  mensajePerdido: { fontSize: 20, fontWeight: 'bold', color: '#dc2626' },
  botones: { flexDirection: 'row', gap: 14 },
  boton: {
    width: 64,
    height: 64,
    borderRadius: 32,
    backgroundColor: '#2563eb',
    alignItems: 'center',
    justifyContent: 'center',
  },
  emojiBoton: { fontSize: 28 },
  botonJugarDeNuevo: { backgroundColor: '#2563eb', paddingVertical: 12, paddingHorizontal: 24, borderRadius: 8 },

});
Las cuatro fases reutilizan el mismo patrón: un objeto GANA_A con las reglas del juego y una función determinarGanador() que no cambia de una fase a otra — lo único que crece es el estado que la envuelve (marcador, condición de fin de partida). Es la misma idea de progresión que el Ahorcado y el Arkanoid, pero sin necesitar una API externa ni gestos.
