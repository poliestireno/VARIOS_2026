Variables: let y const

Una variable es una caja con nombre donde guardas un dato para usarlo más adelante. En JavaScript moderno hay dos formas de crearlas: let, para valores que van a cambiar, y const, para valores que no.

const nombreCurso = "React Native";
nombreCurso = "Otro nombre";
// ❌ TypeError: Assignment to constant variable.

let intentos = 0;
intentos = intentos + 1;
// ✅ funciona: "intentos" ahora vale 1

La regla práctica es simple: empieza siempre por const. Si el código te obliga a reasignar esa variable más adelante, cámbiala a let. Declarar algo como const no es solo una preferencia de estilo — es una promesa que el propio lenguaje comprueba por ti: si tú o un compañero de equipo la reasignáis por error, JavaScript avisa con un error antes de que el bug llegue más lejos.

Es posible que veas código antiguo (o tutoriales viejos) usando una tercera palabra, var. Hoy se considera obsoleta, y es importante entender por qué:

if (true) {
  var x = 10;
}
console.log(x); // 10 -> "var" se escapa del bloque { }

if (true) {
  let y = 10;
}
console.log(y); // ❌ ReferenceError: y is not defined
Por qué evitar var

let y const respetan los bloques { } — una variable creada dentro de un if o un bucle solo existe ahí dentro. var ignora esos límites y “se escapa”, lo que en programas grandes provoca bugs muy difíciles de rastrear: una variable que crees local en realidad está pisando otra con el mismo nombre en otra parte del archivo.

Tipos de datos primitivos

Cada valor en JavaScript tiene un tipo. Hoy nos interesan tres, los que vas a usar constantemente:

  • number — cualquier número, entero o decimal: 32, 3.5, -8. No existe un tipo separado para decimales.
  • string — texto, entre comillas simples, dobles o invertidas: "Ana", 'Ana'.
  • boolean — solo dos valores posibles: true o false. Es el tipo que usan las decisiones.
let edad = 32;             // number
let nombre = "Ana";        // string
let esEstudiante = true;   // boolean

console.log(typeof edad);          // "number"
console.log(typeof nombre);        // "string"
console.log(typeof esEstudiante);  // "boolean"

typeof es un operador que te dice el tipo de cualquier valor — muy útil cuando algo no se comporta como esperas y quieres comprobar qué tipo de dato tienes realmente entre manos.

Los string se pueden unir con +, y JavaScript convierte automáticamente los números a texto cuando hace falta:

let mensaje = "Tienes " + edad + " años";
console.log(mensaje); // "Tienes 32 años"

Operadores: aritméticos y de comparación

Los operadores aritméticos hacen cálculos, igual que en una calculadora:

console.log(5 + 3);   // 8   -> suma
console.log(10 - 4);  // 6   -> resta
console.log(3 * 4);   // 12  -> multiplicación
console.log(10 % 3);  // 1   -> resto de la división (módulo)
console.log(2 ** 3);  // 8   -> potencia (2 elevado a 3)

El módulo (%) es el que menos se usa fuera de clase y el más importante para lo que viene: te dice el resto que sobra al dividir. Es la herramienta clásica para saber si un número es par (n % 2 === 0) o múltiplo de otro — la usaremos en la sesión 2.

Los operadores de comparación devuelven siempre un boolean: true o false. Aquí está la trampa más común del lenguaje:

console.log("5" == 5);   // true  -> compara solo el VALOR, convierte tipos
console.log("5" === 5);  // false -> compara VALOR Y TIPO, sin convertir nada

console.log(5 > 3);    // true
console.log(5 >= 5);   // true
console.log(5 !== "5"); // true -> tipos distintos, "!==" es lo opuesto a "==="
Usa siempre === y !==

== convierte tipos antes de comparar, y esas conversiones tienen resultados poco intuitivos: 0 == false es true, y "" == false también. === nunca convierte nada, así que se comporta exactamente como esperas. Norma de la clase: === y !== siempre, == y != nunca.

Condicionales: if / else

Un condicional ejecuta un bloque de código solo si una condición es verdadera (true). Con else if encadenas más condiciones, y else es el caso por defecto, el que se ejecuta si ninguna de las anteriores se cumplió.

let temperatura = 38;

if (temperatura >= 38) {
  console.log("Tienes fiebre");
} else if (temperatura >= 37) {
  console.log("Febrícula");
} else {
  console.log("Temperatura normal");
}
// -> "Tienes fiebre"

JavaScript evalúa las condiciones en orden, de arriba a abajo, y ejecuta el primer bloque cuya condición sea verdadera; el resto se ignora, aunque también serían ciertas. Por eso el orden importa: si aquí pusiéramos primero temperatura >= 37, una fiebre de 38° se clasificaría (mal) como febrícula.

Compruébalo tú

Cambia temperatura a 36 y vuelve a ejecutar las tres líneas del if. Debería imprimir "Temperatura normal".

Opción A — Clasificador de edad

A1

Declara la variable

Crea una variable con la edad que quieras clasificar. La usaremos como entrada de todo el ejercicio.

let edad = 24; // cambia este número para probar otros casos
A2

Escribe la cadena de decisiones

Tres categorías: menor de edad, adulto, y mayor (65 años o más).

if (edad < 18) {
  console.log("Eres menor de edad");
} else if (edad < 65) {
  console.log("Eres adulto");
} else {
  console.log("Eres mayor");
}
A3

Pruébalo con varios valores

Cambia el número de edad del paso A1 y vuelve a ejecutar el bloque if del paso A2 para cada uno de estos valores: 0, 17, 18, 40, 64, 65, 90.

Fíjate especialmente en

17 debe dar “menor de edad” y 18 debe dar “adulto”: es el caso límite que revela si el operador (< frente a <=) está bien elegido.

Reto extra

Añade más categorías: bebé (menos de 2 años), niño (menos de 12), adolescente (menos de 18). Necesitarás más de un else if encadenado — y pensar bien el orden.

Opción B — Calculadora de IMC

B1

Declara peso y altura

El Índice de Masa Corporal necesita dos datos: el peso en kilogramos y la altura en metros.

let peso = 70;     // kilogramos
let altura = 1.75; // metros
B2

Calcula el IMC

La fórmula es peso dividido entre la altura al cuadrado. Usa el operador de potencia que vimos antes.

let imc = peso / (altura ** 2);
console.log(imc); // 22.857142857142858
B3

Clasifica el resultado

Usa las cuatro franjas estándar de la OMS.

if (imc < 18.5) {
  console.log("Bajo peso");
} else if (imc < 25) {
  console.log("Peso normal");
} else if (imc < 30) {
  console.log("Sobrepeso");
} else {
  console.log("Obesidad");
}
// -> "Peso normal"
B4

Redondea el resultado

22.857142857142858 no es un número para enseñarle a nadie. toFixed(1) lo redondea a un decimal y lo convierte en texto, listo para mostrar.

console.log("Tu IMC es " + imc.toFixed(1));
// -> "Tu IMC es 22.9"
Reto extra

Cambia peso y altura por tus propios datos (o inventados) y comprueba el resultado. Si trabajas en el navegador, prueba a pedir los datos con prompt("¿Cuál es tu peso en kg?") en vez de escribirlos a mano — prompt() siempre devuelve texto, así que necesitarás convertirlo con Number(...) antes de calcular.
