Presentación

En el ámbito de la programación vivimos una época en la que cada poco tiempo surgen nuevas herramientas y lenguajes capaces de aportar nuevas funcionalidades a quien desarrolla software. Sin embargo, por muchos lenguajes nuevos que aparezcan, hay una constante: Python es uno de los principales lenguajes de programación del mundo. Lo confirman los numerosos rankings de consultoras tecnológicas y repositorios de código, y se debe a su gran capacidad de adaptarse a infinidad de usos: desde un simple servicio de consola hasta un sistema que genera dashboards tras analizar cantidades ingentes de datos, pasando por una interfaz gráfica o el front y el back de un servicio web. Por eso es tan importante tener muy claras las bases del lenguaje — estamos ante lo que se conoce como la navaja suiza de los lenguajes de programación.

01

Qué es Python

Python es un lenguaje de programación interpretado de alto nivel: no necesita un compilador para poder ejecutar el código, sino que lo hace de forma directa, línea a línea. Sus primeros usos son de los años 90, pero ha cobrado especial importancia en los últimos años gracias a ámbitos como la ciencia de datos y la inteligencia artificial.

Su objetivo principal es facilitar la programación, reduciendo la complejidad sin perder potencia. Es un lenguaje fácil de leer y escribir, con una sintaxis clara que se acerca al lenguaje humano — una opción ideal para quien empieza. Su diseño enfatiza la legibilidad del código, lo que mejora la colaboración entre programadores y reduce la probabilidad de errores.

Al ser un lenguaje de alto nivel, abstrae muchas complejidades técnicas que otros lenguajes sí exigen, como la gestión manual de memoria o el uso de punteros — permite centrarse en resolver el problema, sin preocuparse por la administración de memoria o la optimización del hardware.

Un lenguaje multiparadigma

Python admite varios estilos de programación: imperativo, orientado a objetos y funcional. Esa versatilidad es una de las razones por las que se adapta a tantos tipos de proyecto distintos — y es también el motivo de que este módulo llegue, más adelante, hasta la programación orientada a objetos (RA6).

02

Usos de Python

  • Desarrollo web: frameworks como Django y Flask.
  • Ciencia de datos y análisis: librerías como NumPy y Pandas lo han convertido en el lenguaje de referencia para análisis de datos, estadística y machine learning.
  • Automatización: tareas repetitivas, como manipular archivos o interactuar con APIs.
  • Aplicaciones de escritorio: interfaces gráficas con bibliotecas como Tkinter.
  • Inteligencia artificial y aprendizaje automático: librerías como TensorFlow y Keras.
  • Scripting y administración de sistemas: scripts para gestionar servidores, sistemas de archivos y redes.
03

Instalación y configuración del entorno

Antes de desarrollar nada, hay que configurar bien el entorno de trabajo. Con Python hay dos grandes tipos de entorno: online y local.

Google Colab, para ejecuciones rápidas

Para ejecutar código en la nube, sin instalar nada, Google Colab es una magnífica solución para crear cuadernos online donde colocar scripts de Python y ejecutarlos desde cualquier sitio. Accede desde colab.research.google.com.

Para un entorno local, lo primero es instalar Python: descárgalo desde la página oficial (python.org, sección Download) para tu sistema operativo.

En Windows: Add Python to PATH

Durante la instalación en Windows es muy importante marcar la opción “Add Python to PATH” — así Python queda configurado como variable de entorno y se puede invocar desde cualquier terminal, sin indicar su ruta completa.

Para comprobar que la instalación ha ido bien, abre la terminal (o cmd) y ejecuta:

$ python --version   # Windows
$ python3 --version  # macOS

Si obtienes un número de versión, ya estás listo para instalar y configurar el IDE.

04

Selección del IDE

El IDE es el programa donde se crean y ejecutan los scripts. En un entorno local hay varias opciones: Visual Studio Code, PyCharm o Jupyter (que aunque también se puede usar online, su uso más habitual es local). Por su facilidad de uso y la cantidad de extensiones disponibles, en este módulo usaremos Visual Studio Code.

1

Descarga VS Code

Desde la página oficial, sección Download: code.visualstudio.com.

2

Instala las extensiones recomendadas

1

Python

Librería oficial de Microsoft que permite generar y ejecutar código Python de forma sencilla.

2

Pylance

Librería oficial de Microsoft que analiza el código para comprobar que se ejecutará correctamente.

3

Black Formatter

Librería oficial de Microsoft que formatea el código Python siguiendo los estándares del lenguaje.

05

Comprobación: primer script

Con el IDE y las extensiones instaladas, toca comprobar que todo funciona. Crea una carpeta en VS Code, y dentro un archivo nuevo (botón derecho → Nuevo archivo) llamado 01_inicio.py:

print("Ejecución correcta")

Pulsa el botón de ejecutar (parte superior derecha del editor) y debería aparecer “Ejecución correcta” en la consola de ejecución. print() es el método más básico de salida por consola — lo verás constantemente a partir de ahora.
