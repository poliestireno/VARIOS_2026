01

Reglas básicas de sintaxis

Python es un lenguaje interpretado: no necesita compilador, así que las líneas de código se ejecutan una a una. Por eso su sintaxis es bastante simple. Algunos elementos que conviene tener siempre presentes:

Comentarios

Son las partes del código que no se ejecutan, y sirven como documentación. Para una sola línea se usa #; para varias líneas, comillas triples """ o '''.

# petición de datos al usuario
nombre = input("¿Cuál es tu nombre? ")
correo = input("¿Cuál es tu correo? ")
edad = int(input("¿Cuál es tu edad? "))

"""
salida de datos por consola
método de salida por consola con print y mostrar los datos obtenidos
"""
print(
    f"El correo de {nombre} es {correo}, el cual cuenta con {len(correo)} caracteres con {edad} años"
)

Variables sin tipado explícito

Una variable no necesita que se indique su tipo: este se asigna en el momento de darle un valor.

Bloques sin llaves

Es una de las cosas que más llama la atención al llegar de otro lenguaje: un bloque (función, estructura de control…) no se delimita con { }, sino con indentación (tabulación o sangría).

if edad < 18:
    print("El usuario es menor de edad, por lo que no puede acceder a la plataforma")
else:
    print(
        f"El correo de {nombre} es {correo}, el cual cuenta con {len(correo)} caracteres con {edad} años"
    )

Sin punto y coma

No hace falta ; para indicar el final de una línea — el propio salto de línea (Enter) ya lo indica.

02

Variables

Las variables almacenan datos para poder acceder a ellos (o modificarlos) desde distintas partes del código. No hace falta indicar el tipo al declararlas — se determina al asignarles un valor — pero sí conviene conocer los tipos principales:

  • int: números enteros, sin decimales.
  • float: números con decimales, con el punto (.) como separador.
  • str: cadena de caracteres, entre comillas.
  • bool: True o False, muy usado en decisiones lógicas.
  • list: lista ordenada y dinámica.
  • tuple: lista ordenada y estática (no se puede modificar).
  • dict: diccionario, asociando pares clave–valor.

No son todos los tipos que existen — también se pueden crear tipos propios con objetos —, pero sí los principales.

Cambiar de tipo y consultarlo

Se puede convertir una variable a otro tipo llamando al tipo de destino como si fuera una función, pasándole la variable a convertir:

numeroDecimal = 34.87
numeroEntero = int(numeroDecimal)
print(f"El número decimal es {numeroDecimal} y el número entero es {numeroEntero}")

Y para saber de qué tipo es una variable, el método type():

print(type(numeroDecimal))
03

Métodos

Los métodos son las funcionalidades que se pueden ejecutar sobre un objeto. Se pueden crear métodos propios o usar los que el lenguaje ya trae. Para ejecutar uno, basta con escribir su nombre y, entre paréntesis, los parámetros que necesite:

print("Mensaje a mostrar")

Algunos de los métodos más habituales:

  • input(): lee un dato por teclado. Recibe como parámetro el texto de la petición.
  • print(): escribe por consola el texto indicado.
  • upper(), lower(): pasan un texto a mayúsculas o minúsculas.
  • strip(): elimina espacios en blanco al principio y al final de un texto.
  • replace(): sustituye un grupo de caracteres por otro.
  • find(): devuelve la posición de un grupo de caracteres dentro de una palabra.
  • len(): devuelve la longitud del objeto — caracteres en un string, elementos en una lista.
  • type(): devuelve la clase del objeto.
  • int(), float(): convierten al tipo correspondiente.
# Pedimos al usuario que introduzca su nombre
nombre = input("Introduce tu nombre: ")

# Limpiamos los espacios en blanco
nombre_limpio = nombre.strip()

# Mostramos el nombre en diferentes formatos
print("En mayúsculas:", nombre_limpio.upper())
print("En minúsculas:", nombre_limpio.lower())

# Reemplazamos un nombre por otro, por ejemplo si alguien se llama "Juan"
nombre_modificado = nombre_limpio.replace("Juan", "Juanjo")
print("Nombre con modificación:", nombre_modificado)

# Buscamos si el apellido "Gómez" está en el nombre
posicion = nombre_limpio.find("Gómez")
if posicion != -1:
    print("El apellido 'Gómez' empieza en la posición:", posicion)
else:
    print("El apellido 'Gómez' no se encuentra en el nombre.")

# Mostramos la longitud del nombre
print("Número de caracteres:", len(nombre_limpio))

# Mostramos el tipo de dato que es la variable nombre_limpio
print("El tipo de dato de la variable es:", type(nombre_limpio))

# Convertimos edad a número entero
edad_str = input("¿Cuántos años tienes? ")
edad = int(edad_str)
print("Edad como número entero:", edad)

# Mostramos también esa edad como número decimal (float)
edad_float = float(edad)
print("Edad como número decimal:", edad_float)
04

Operadores

Aritméticos

  • + suma, - resta, * multiplicación, ** potencia.
  • / división — entre dos enteros da como resultado un float.
  • // división entera.
  • % módulo (resto de la división).
a = 10
b = 3

suma = a + b              # 13
resta = a - b              # 7
multiplicacion = a * b     # 30
division = a / b           # 3.333... (float)
division_entera = a // b   # 3
modulo = a % b              # 1
potencia = a ** b          # 10^3 = 1000

De comparación

Devuelven siempre un booleano: >, >=, <, <=, == (igual), != (distinto).

a = 10
b = 5

igual = a == b            # False
diferente = a != b        # True
mayor_que = a > b         # True
menor_que = a < b         # False
mayor_o_igual = a >= b    # True
menor_o_igual = a <= b    # False

Lógicos

  • and: verdadero solo si todas las condiciones lo son. Si la primera es falsa, el resto no se evalúa.
  • or: verdadero si al menos una condición lo es. Si la primera es verdadera, el resto no se evalúa.
  • not: invierte el valor booleano.
a = True
b = False

resultado_and = a and b   # True si ambos son True
resultado_or = a or b     # True si al menos uno es True
resultado_not_a = not a   # invierte el valor de a

Ejercicio

Imagina que tienes dos jugadores que introducen sus puntuaciones. El programa debe:

  • Pedir el nombre y la puntuación de cada jugador.
  • Mostrar operaciones aritméticas entre las puntuaciones (suma, diferencia, etc.).
  • Comparar las puntuaciones y mostrar los resultados (==, >, <, etc.).
  • Mostrar expresiones lógicas compuestas sobre quién tiene más puntos, si son iguales, etc.
  • Mostrar todos los resultados como parte de un resumen.
Siguiente: estructuras de control y datos — condicionales, bucles, y las colecciones (listas, tuplas, diccionarios, conjuntos).
