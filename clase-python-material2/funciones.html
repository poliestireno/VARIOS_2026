00

Presentación

A medida que los programas crecen en tamaño y complejidad, se hace indispensable dividir el código en bloques manejables y reutilizables. Aquí entran las funciones: permiten organizar el código de forma lógica, mejorar su legibilidad y facilitar el mantenimiento.

Imagina un programa donde ciertas funcionalidades son muy similares, coincidiendo en la mayoría de sus líneas. Para quien empieza, escribir dos veces el mismo código en partes distintas del programa no supone gran esfuerzo; pero según se adquiere soltura, esa práctica se vuelve pesada y nada recomendable. Es muy habitual tener que repetir ciertas acciones, o querer organizar mejor el código — no solo para que funcione de forma más eficaz, sino para que sea más fácil de leer, mantener y reutilizar. Un código bien modularizado simplifica mucho la tarea de retomarlo tras un tiempo sin tocarlo, o de leer un código heredado de otro equipo.

Una función no es más que un bloque de código con nombre, que se puede ejecutar siempre que haga falta sin volver a escribir todo lo que contiene. La idea es que encapsule una tarea concreta: mostrar un mensaje, calcular un promedio, validar una entrada… En vez de repetir el mismo código varias veces, se define una sola vez en una función y se reutiliza cada vez que se necesite.

Muchas veces el código no es siempre exactamente igual — hay datos que cambian, aunque la estructura general se mantenga. Aquí entran los parámetros: datos de entrada que la función admite para “personalizarse” cada vez que se la llama.

Las funciones, además de evitar la repetición, permiten estructurar mejor el programa: en vez de tener todo el código seguido, se divide en partes pequeñas, cada una con una función clara — más comprensible, más fácil de mantener y de depurar, siguiendo uno de los principales dogmas de la informática: divide y vencerás. También facilitan el trabajo en equipo: cada persona puede encargarse de una parte del código contenida en funciones distintas, que después se combinan en el programa completo.

Python ya trae funciones predefinidas, como print(), input() o len() — pero también se pueden crear funciones propias e incorporarlas al programa.

01

Definición y uso

Antes de ver las palabras reservadas, un inciso sobre cómo nombrar funciones: lo más recomendable es usar nombres que describan claramente lo que hacen — claros, específicos y descriptivos, evitando abreviaturas confusas o palabras genéricas. Por convención se usan minúsculas, y si el nombre tiene varias palabras se separan con guion bajo (_): es el conocido snake_case. Si una función calcula la media de una lista de notas, un buen nombre sería calcular_media, no algo genérico como funcion1 o mediaNotas.

A diferencia de otros lenguajes, definir una función en Python es muy sencillo: al no existir modificadores de acceso, basta con la palabra reservada def, seguida del nombre de la función.

def saludar():
    print("Hola desde la primera funcion")

De nuevo, no existen llaves para delimitar el bloque de la función: se hace con indentación (4 espacios). Para ejecutar el código de saludar, se la llama incluyendo los paréntesis:

print("Vamos a proceder a la llamada de la funcion")
saludar()
02.1

Uso de parámetros

Al crear una función se le puede indicar una serie de datos de entrada — los parámetros — para personalizar lo que la función hace en cada llamada. Un parámetro es solo la referencia del dato dentro de la función; hasta que la función no se llama, no tiene ningún valor real.

def saludar(nombre):
    print(f"Hola {nombre}, espero que te encuentres bien.")

saludar("Juan")

La función admite un parámetro, nombre, que hay que pasarle al llamarla — el resultado sería “Hola Juan, espero que te encuentres bien”. Si se llama sin pasar el parámetro, se obtiene un error. Se pueden indicar tantos parámetros como haga falta:

def saludar(nombre, apellido, repeticiones):
    for i in range(repeticiones):
        print(f"Hola {nombre} {apellido}, espero que te encuentres bien.")

saludar("Juan", "Gomez", 3)

Este ejemplo repite el saludo tres veces, incluyendo también el apellido.

Para evitar el error al no pasar un parámetro, se puede indicar un valor por defecto: un valor que se asigna al parámetro si no se indica nada en la llamada.

def saludar(nombre, apellido, repeticiones=1):
    for i in range(repeticiones):
        print(f"Hola {nombre} {apellido}, espero que te encuentres bien.")

saludar("Marta", "Jiménez")       # repeticiones toma el valor 1
saludar("Marta", "Jiménez", 3)    # repeticiones toma el valor 3
Los parámetros con valor por defecto van al final

Es imprescindible que los parámetros con valor por defecto estén al final de la lista de parámetros:

# ❌ uso incorrecto
def saludar(nombre="Juan", apellido, edad): ...

# ✅ uso correcto
def saludar(nombre, apellido, edad=18, experiencia=True): ...

En la primera función, al usar parámetros asociados a una posición, sería imposible ubicar el segundo parámetro si no se indica el primero. En la segunda, la llamada solo es válida si no se indica ni edad ni experiencia, o si no se indica solo experiencia — nunca al revés.

02.2

Tipos de parámetros

Los parámetros separados por comas, con o sin valor por defecto, se conocen como parámetros posicionales, porque se asocian a una posición concreta:

def funcionParametros(param1, param2, param3):
    print(f"param1: {param1}, param2: {param2}, param3: {param3}")

funcionParametros("valor1", "valor2", "valor3")

Para mejorar la legibilidad de una llamada, se pueden usar parámetros nombrados, sustituyendo la posición por el nombre del parámetro:

funcionParametros(param1="valor2", param2="valor3", param3="valor1")

Así queda mucho más claro qué dato corresponde a cada parámetro.

02.3

Uso de *args y **kwargs

A veces hace falta pasar un número indeterminado de datos, y ni los parámetros posicionales ni los nombrados sirven — por ejemplo, una función que calcule la media de una serie de números sin saber de antemano cuántos son. Para eso está *args, que convierte todos los parámetros pasados en una tupla (no mutable) para usarla dentro de la función.

def calculo_media(*notas):
    media = 0.0
    print(f"Procedo a calcular la media de {len(notas)} notas")
    for i in notas:
        media += i

    media = media / len(notas)
    print(f"La media obtenida es de: {media}")

calculo_media(1, 5, 7, 3)
calculo_media(4, 9, 6)

Con *args, al llamar a la función se pueden pasar tantos parámetros como se quiera.

La otra posibilidad es **kwargs: muy similar, pero los parámetros deben ir nombrados, y se convierten en un diccionario dentro de la función.

def importar_usuario(**kwargs):
    print("Los datos pasados del usuario son:")
    for key, value in kwargs.items():
        print(f"{key}: {value}")

importar_usuario(nombre="Juan", apellido="Gomez", edad=25, ciudad="Madrid")

Cada parámetro nombrado pasa a formar parte de un diccionario, donde la clave es el nombre del parámetro y el valor, el dato asociado. Es especialmente útil cuando la información que hay que pasar a la función no es siempre la misma — la función puede convertir todos los datos recibidos en una única estructura. Ambos tipos, *args y **kwargs, se pueden combinar en la misma función.
