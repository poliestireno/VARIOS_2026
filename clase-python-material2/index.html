Bloque 1 · 34% de la evaluación

RA1 + RA2 · Fundamentos del lenguaje

2 desafíos · 12 días de grupo · Eval. 1

RA1. Reconoce la estructura de un programa informático, identificando y relacionando los elementos propios del lenguaje de programación utilizado. RA2. Escribe y depura código, analizando y utilizando las estructuras de control del lenguaje.

Teoría

T1

Presentación: qué es Python y cómo montar el entorno

Qué es Python, para qué se usa, instalación del intérprete, y elección y configuración de VS Code con sus extensiones. Primer script de comprobación.

T2

Sintaxis básica

Comentarios, indentación en vez de llaves, variables sin tipado explícito, tipos de datos, métodos de uso común y operadores aritméticos, de comparación y lógicos.

T3

Estructuras de control

Condicionales (if / if-else / if-elif-else, match) y bucles (for, while) — la parte de control del flujo de la unidad de estructuras de control y datos.
