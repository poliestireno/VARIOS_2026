01

Qué es SQLite

SQLite es una base de datos embebida que no requiere instalación ni configuración de un servidor — ligera y rápida, ideal para proyectos pequeños/medianos o almacenamiento local en apps móviles, web y sistemas embebidos. Todo se gestiona en un solo archivo, lo que la hace totalmente portable.

  • Transaccional: soporta las propiedades ACID (Atomicidad, Consistencia, Aislamiento, Durabilidad).
  • Código abierto y compatible con múltiples plataformas y lenguajes (PHP, Python, Java, C/C++…).
02

Crear y manejar bases de datos

$ sudo apt update && sudo apt install sqlite3

$ sqlite3 nombre_de_base_datos.db
-- abre (o crea) el fichero y entra en el shell de SQLite
CREATE TABLE empleados (
    id INTEGER PRIMARY KEY,
    nombre TEXT NOT NULL,
    departamento TEXT,
    salario REAL
);

Tipos de datos comunes: INTEGER, TEXT, REAL, BLOB. Para listar las tablas existentes: .tables.

03

Manipulación de datos

INSERT INTO empleados (nombre, departamento, salario)
VALUES ('Juan Pérez', 'IT', 2500.50);

SELECT * FROM empleados;

SELECT nombre, salario FROM empleados WHERE departamento = 'IT';

UPDATE empleados SET salario = 2700 WHERE nombre = 'Juan Pérez';

DELETE FROM empleados WHERE nombre = 'Juan Pérez';
04

Claves primarias y restricciones

Una clave primaria identifica de forma única cada registro. Con AUTOINCREMENT se genera automáticamente:

CREATE TABLE departamentos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nombre TEXT NOT NULL
);

CREATE TABLE usuarios (
    id INTEGER PRIMARY KEY,
    email TEXT NOT NULL UNIQUE,
    password TEXT NOT NULL
);

NOT NULL impide un campo vacío; UNIQUE impide valores repetidos en ese campo.

05

Funciones agregadas y GROUP BY

SELECT SUM(salario) FROM empleados WHERE departamento = 'IT';

SELECT departamento, COUNT(*)
FROM empleados
GROUP BY departamento;

SUM, COUNT y AVG son las funciones agregadas más habituales; GROUP BY agrupa filas que comparten valor en una columna, para aplicar la función agregada a cada grupo por separado.

06

Joins

-- INNER JOIN: solo filas con coincidencia en ambas tablas
SELECT empleados.nombre, departamentos.nombre
FROM empleados
JOIN departamentos ON empleados.departamento_id = departamentos.id;

-- LEFT JOIN: todas las filas de la izquierda, NULL si no hay coincidencia
SELECT empleados.nombre, departamentos.nombre
FROM empleados
LEFT JOIN departamentos ON empleados.departamento_id = departamentos.id;
07

Seguridad

Al vivir en un único fichero, los permisos de ese fichero son la seguridad de la base de datos:

$ chmod 600 nombre_de_base_datos.db
$ chown root nombre_de_base_datos.db
# solo el propietario puede leer y escribir en el archivo

Igual que en cualquier motor SQL, hay que sanitizar la entrada del usuario para evitar inyección SQL — usando siempre consultas preparadas con parámetros, sobre todo si SQLite se usa desde una app web o móvil.

08

Índices, VACUUM y EXPLAIN QUERY PLAN

sqlite> CREATE INDEX idx_nombre ON empleados(nombre);
-- acelera las búsquedas por esa columna

sqlite> VACUUM;
-- compacta la base de datos y reduce el espacio en disco

EXPLAIN QUERY PLAN muestra cómo va a ejecutar SQLite una consulta — si recorrerá toda la tabla (full table scan) o si aprovechará un índice. Es la herramienta principal para justificar cualquier optimización.

sqlite> EXPLAIN QUERY PLAN SELECT * FROM empleados WHERE nombre = 'Juan';
0|0|0|SCAN TABLE empleados
-- sin índice: recorre toda la tabla

sqlite> CREATE INDEX idx_nombre ON empleados(nombre);
sqlite> EXPLAIN QUERY PLAN SELECT * FROM empleados WHERE nombre = 'Juan';
0|0|0|SEARCH TABLE empleados USING INDEX idx_nombre (nombre=?)
-- con índice: búsqueda directa, mucho más rápida
09

Integración y herramientas

<?php
$db = new SQLite3('mi_base_datos.db');
$resultado = $db->query('SELECT * FROM empleados');
while ($fila = $resultado->fetchArray(SQLITE3_ASSOC)) {
    echo "Nombre: " . $fila['nombre'] . " - Salario: " . $fila['salario'];
}
$db->close();
?>

Herramientas de administración: sqlite3 (CLI incluida con SQLite) y DB Browser for SQLite, una herramienta gráfica gratuita para explorar datos y exportar a CSV.
