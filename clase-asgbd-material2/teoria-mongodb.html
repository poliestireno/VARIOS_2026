01

Qué es MongoDB

MongoDB es una base de datos NoSQL de tipo documento. En vez de tablas y filas, almacena datos en documentos similares a JSON (formato BSON internamente), lo que la hace flexible: cada documento puede tener un esquema distinto, sin campos predefinidos obligatorios para toda la colección.

02

Características principales

  • Modelo de datos basado en documentos: cada documento puede tener un esquema flexible.
  • NoSQL: no requiere esquemas fijos, ideal para datos no o semiestructurados.
  • Escalabilidad horizontal: permite repartir los datos entre varios servidores mediante sharding.
  • Consultas potentes: filtros, proyecciones, agregaciones y búsquedas indexadas.
  • Alta disponibilidad: replicación con recuperación automática ante fallos.
  • Índices: sobre cualquier campo, para acelerar búsquedas.
  • Agregaciones: el aggregation pipeline, una tubería de etapas de transformación de datos.

04

JSON: la sintaxis de un documento

JSON (JavaScript Object Notation) es un formato de intercambio de datos ligero basado en texto — fácil de leer para humanos y máquinas, compatible con prácticamente cualquier lenguaje. Un objeto JSON es un conjunto de pares clave-valor entre llaves {}; un array es una lista ordenada entre corchetes [].

{
  "name": "Alice",
  "age": 30,
  "email": "alice@example.com",
  "skills": ["JavaScript", "Python", "SQL"],
  "address": {
    "street": "123 Main St",
    "city": "Springfield"
  }
}

Tipos de dato JSON: string, number, boolean, null, array y object. Un documento MongoDB es, en esencia, exactamente esto — guardado internamente en BSON, la versión binaria de JSON.

05

Operadores de consulta

Comparación: $eq, $ne, $gt, $gte, $lt, $lte, $in, $nin.

Lógicos: $and, $or, $not, $nor.

Elementos: $exists (comprueba si un campo existe), $type (filtra por tipo de dato).

Evaluación: $regex (expresiones regulares), $expr (expresiones de agregación dentro de una consulta), $mod, $text.

Arrays: $all, $elemMatch, $size, $slice.

db.trees.find({ height: { $gt: 30 } });
db.trees.find({ $or: [{ height: 50 }, { age: { $gt: 20 } }] });
06

Relaciones entre documentos

MongoDB no tiene claves foráneas, pero se pueden modelar los mismos tres tipos de relación de siempre, referenciando _id de un documento desde otro:

  • 1:1 — un árbol y su clasificación ecológica: se guarda el _id de la clasificación dentro del documento del árbol.
  • 1:N — un árbol y sus avistamientos: cada avistamiento guarda a qué árbol pertenece.
  • N:M — árboles y animales: hace falta una colección intermedia (igual que una tabla puente en SQL) que relacione ambos lados.
-- 1:1
db.trees.updateOne(
  { name: "Roble" },
  { $set: { ecological_classification_id: ObjectId("64891b2e5d2f4a38b89e0c1a") } }
);

-- 1:N
db.sightings.insertMany([
  { tree_name: "Pino", location: "Pirineos" },
  { tree_name: "Pino", location: "Montseny" }
]);

-- N:M, vía colección intermedia
db.tree_animal.insertMany([
  { tree_name: "Roble", animal_name: "Ardilla" },
  { tree_name: "Roble", animal_name: "Pájaro carpintero" }
]);
07

$lookup en detalle

$lookup es el operador de agregación que une datos de colecciones distintas en una sola consulta — el equivalente de un JOIN en SQL. Sirve para: unir colecciones relacionadas, simular relaciones sin esquema fijo, y evitar hacer varias consultas separadas.

-- bibliotecas y sus libros disponibles
db.libraries.aggregate([
  {
    $lookup: {
      from: "books",
      localField: "_id",
      foreignField: "library_id",
      as: "available_books"
    }
  }
]);

from es la colección con la que unir; localField/foreignField son los campos que deben coincidir (a un lado y otro); as es el nombre del nuevo campo, que llegará como un array con todos los documentos relacionados encontrados (relación 1:N). Se puede combinar con $project a continuación para quedarse solo con los campos que interesan del resultado.

08

MongoDB Compass

Compass es el cliente visual oficial: conectar con la URI del servidor, Create Database para crear base de datos y colección inicial, Insert Document para añadir documentos en JSON, la barra de búsqueda superior para filtrar (mismo formato que find()), y los iconos de lápiz/papelera para actualizar o eliminar un documento. Ventajas frente a la terminal: interfaz amigable, visualización de estructuras y estadísticas, asistentes para filtros/proyecciones, gestión de índices sin comandos, y un generador visual de pipelines de agregación.
