01

Instalación y consola

$ sudo apt update && sudo apt install postgresql postgresql-contrib
$ sudo systemctl enable --now postgresql

# PostgreSQL crea un usuario del sistema llamado "postgres", dueño de todo
$ sudo -i -u postgres
$ psql

A diferencia de MySQL, PostgreSQL delega la autenticación en el propio sistema operativo por defecto: para entrar como postgres hay que ser ese usuario Linux (o usar el modo peer/md5 configurado en pg_hba.conf).

02

Bases de datos y tablas

CREATE DATABASE EquitacionSuave;
\c EquitacionSuave

CREATE TABLE jinetes (
    id SERIAL PRIMARY KEY,
    nombre TEXT NOT NULL,
    apellido TEXT,
    categoria TEXT,
    experiencia_años INTEGER
);

CREATE TABLE caballos (
    id SERIAL PRIMARY KEY,
    nombre TEXT NOT NULL,
    raza TEXT,
    edad INTEGER,
    jinete_id INTEGER REFERENCES jinetes(id)
);

SERIAL es el equivalente de PostgreSQL a AUTOINCREMENT: genera automáticamente un entero creciente. \c nombre_bd es el comando de psql para cambiar de base de datos conectada.

03

Roles y permisos

En PostgreSQL no existe una distinción estricta entre “usuario” y “rol” — un usuario es simplemente un rol con permiso de LOGIN.

CREATE ROLE admin_equitacion WITH LOGIN CREATEDB PASSWORD '...';
CREATE ROLE user_consultas WITH LOGIN PASSWORD '...';
CREATE ROLE user_lectura WITH LOGIN PASSWORD '...';

GRANT SELECT ON jinetes, caballos TO user_consultas;
GRANT SELECT ON jinetes, caballos TO user_lectura;
GRANT SELECT, INSERT, UPDATE, DELETE ON jinetes, caballos TO admin_equitacion;

CREATEDB permite al rol crear nuevas bases de datos; sin ese atributo, un rol solo puede operar dentro de las bases a las que se le ha dado acceso explícito.

04

JSON y ARRAY

PostgreSQL admite columnas con tipos de datos que van más allá del modelo relacional clásico:

ALTER TABLE jinetes ADD COLUMN detalles_competencias JSON;

INSERT INTO jinetes (nombre, apellido, detalles_competencias)
VALUES ('Laura', 'Gómez',
        '{"competencias": ["Salto", "Doma"], "victorias": 3}');

ALTER TABLE jinetes ADD COLUMN certificaciones TEXT[];

UPDATE jinetes SET certificaciones = ARRAY['Nivel 1', 'Nivel 2']
WHERE nombre = 'Laura';

JSON guarda datos semiestructurados dentro de una columna relacional normal; ARRAY guarda una lista de valores del mismo tipo en un único campo, sin necesitar una tabla aparte para relaciones simples.

05

Vistas materializadas

Una vista normal recalcula su consulta cada vez que se lee. Una vista materializada guarda el resultado físicamente, como una tabla — mucho más rápida de leer, a cambio de quedar desactualizada hasta que se refresca a mano.

CREATE MATERIALIZED VIEW vista_jinetes_avanzados AS
SELECT * FROM jinetes WHERE categoria = 'Avanzado';

REFRESH MATERIALIZED VIEW vista_jinetes_avanzados;
-- recalcula el contenido con los datos actuales de "jinetes"
06

Herencia de tablas

PostgreSQL permite que una tabla herede las columnas de otra, y añada las suyas propias — útil para modelar variantes de un mismo concepto sin repetir columnas.

CREATE TABLE equipo_base (
    id SERIAL PRIMARY KEY,
    nombre TEXT,
    tipo TEXT
);

CREATE TABLE equipo_de_salto (
    altura_maxima REAL
) INHERITS (equipo_base);
-- equipo_de_salto tiene id, nombre, tipo (heredadas) + altura_maxima (propia)
07

pgAdmin

pgAdmin es la herramienta gráfica oficial de PostgreSQL. Permite hacer todo lo anterior sin escribir SQL a mano: conectar al servidor con las credenciales de postgres, crear la base de datos y sus tablas desde Schemas → public → Tables, insertar y consultar datos con el Query Tool, y crear/gestionar roles desde Login/Group Roles.
