01

Qué es Markdown

Markdown es un lenguaje de marcado ligero: texto plano con una sintaxis mínima (almohadillas, asteriscos, guiones…) que un programa convierte en HTML con formato. Se guarda en archivos .md y se usa en READMEs de GitHub, issues y Pull Requests, Notion, Discord, Slack — y en todo el material de este curso, que empezó siendo Markdown antes de convertirse en estas páginas.

La variante concreta que usa GitHub se llama GFM (GitHub Flavored Markdown): añade extras sobre el Markdown original, como listas de tareas o tablas, que no existen en todas las plataformas pero sí en GitHub.

Vista previa en VS Code

Con un archivo .md abierto, Ctrl+Shift+V abre la vista previa renderizada; Ctrl+K V la abre al lado, en pantalla partida, para ver el código y el resultado a la vez — justo como en esta página.

Énfasis

Negrita con dos asteriscos, cursiva con uno, tachado con dos virgulillas. Se pueden combinar.

Esto es **negrita** y esto es *cursiva*.
También se pueden ***combinar ambas***,
o tachar texto con ~~tachado~~.
Vista previa

Esto es negrita y esto es cursiva. También se pueden combinar ambas, o tachar texto con tachado.

Listas

Sin ordenar

-, * o + funcionan igual como marcador; anidar una lista es indentarla dos espacios.

- Primer elemento
- Segundo elemento
  - Elemento anidado
  - Otro elemento anidado
- Tercer elemento
Vista previa
  • Primer elemento
  • Segundo elemento
    • Elemento anidado
    • Otro elemento anidado
  • Tercer elemento

Ordenada

1. Paso uno
2. Paso dos
3. Paso tres
Vista previa
  1. Paso uno
  2. Paso dos
  3. Paso tres

El número que escribas casi no importa — Markdown renumera solo. Poner 1. en todas las líneas también funciona y evita errores al reordenar pasos a mano.

05

Listas de tareas

Extensión de GFM: una lista normal donde cada elemento empieza por [ ] (pendiente) o [x] (hecho). Muy usada en el README de un proyecto o en la descripción de un Pull Request — en GitHub incluso se pueden marcar haciendo clic, sin editar el Markdown a mano.

- [x] Instalar VS Code
- [x] Clonar el repositorio
- [ ] Hacer el primer commit
- [ ] Subir los cambios

Imágenes

Igual que un enlace, con un ! delante. El texto entre corchetes es el texto alternativo — lo que se lee si la imagen no carga, y lo que usa un lector de pantalla.

Imagen que además es un enlace:
[![Captura](capturas/xampp.png)](https://github.com)

Tablas

Una fila de encabezado, una fila separadora con guiones, y una fila por registro. No hace falta alinear las barras verticales a mano — solo que estén en el mismo orden en cada fila.

| Nombre | Edad | Ciudad |
| --- | --- | --- |
| Ana | 30 | Madrid |
| Luis | 25 | Sevilla |
Vista previa
NombreEdadCiudad
Ana30Madrid
Luis25Sevilla

Los dos puntos en la fila separadora fijan la alineación de esa columna: :--- izquierda, :---: centro, ---: derecha.

| Izquierda | Centro | Derecha |
| :--- | :---: | ---: |
| a | b | c |
Vista previa

abc

El truco de las líneas en blanco

Una línea en blanco separa párrafos. Si escribes dos líneas seguidas sin línea en blanco entre medias, Markdown las junta en un único párrafo. Para forzar un salto de línea sin crear un párrafo nuevo, se dejan dos espacios al final de la línea (invisibles, fáciles de perder sin querer) o se usa directamente la etiqueta HTML <br>.

Notas al pie

Extensión de GFM: una referencia [^etiqueta] en el texto, y en cualquier parte del documento su definición con [^etiqueta]:. Se renderizan como una nota numerada al final del documento, con enlace de ida y vuelta.

El proyecto usa PDO para acceder a la base de datos[^1].

[^1]: No `mysqli`, para poder cambiar de motor de base de datos sin reescribir las consultas.

HTML embebido y caracteres especiales

Dentro de un archivo Markdown se puede mezclar HTML normal — útil para lo que Markdown no cubre, como un bloque plegable con <details>.

<details>
<summary>Haz clic para ver la solución</summary>

Aquí va el contenido oculto, que puede seguir siendo Markdown.

</details>

Cuando un carácter especial de Markdown (* _ # \` [ ]…) tiene que aparecer literal y no como sintaxis, se escapa con una barra invertida delante.

14

Extras de GitHub

Alertas

Una cita especial cuya primera línea es [!NOTE], [!TIP], [!IMPORTANT], [!WARNING] o [!CAUTION]. GitHub la pinta como un aviso de color, con icono — solo se renderiza así en GitHub, no en la vista previa genérica de Markdown.

> [!WARNING]
> Este comando borra la base de datos sin pedir confirmación.
Vista previa (solo en GitHub)
Warning
Este comando borra la base de datos sin pedir confirmación.

Menciones y referencias

@usuario menciona a alguien (le llega una notificación) y #123 enlaza automáticamente al issue o Pull Request número 123 del mismo repositorio. Solo funcionan dentro de GitHub, no en un editor de Markdown genérico.

Emojis

Los códigos cortos :tada:, :bug:, :rocket:… se convierten en emoji (🎉 🐛 🚀) en GitHub, Slack y Discord — no en todas las plataformas de Markdown.
