Recursos transversales

Guías de referencia que no pertenecen a ningún módulo concreto — herramientas que se usan en todos ellos, empezando por cómo escribir y versionar el propio material de cada desafío.

2 guías Referencia, no temario

Antes de entregar cualquier desafío hacen falta estas dos cosas: saber escribir el README o el enunciado con formato (Markdown), y saber subir el código a un repositorio sin perder nada por el camino (Git). Ninguna de las dos es específica de PHP, IAW o ningún otro módulo — se usan siempre.

Markdown: sintaxis completa

Encabezados, listas, enlaces, imágenes, código, tablas, notas al pie y los extras de GitHub — cada uno con el código fuente y su resultado ya renderizado, uno junto al otro.

Para qué sirve: escribir el README de un proyecto, el enunciado de un desafío, o la descripción de un Pull Request.

Git básico desde VS Code

Clonar, preparar y confirmar cambios, subir y bajar con Sync, crear ramas, y resolver un conflicto de fusión — todo desde el panel de Control de código fuente, sin terminal.

Para qué sirve: guardar y compartir el trabajo de cada desafío sin depender de copiar carpetas a mano.
