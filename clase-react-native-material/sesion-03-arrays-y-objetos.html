Arrays y objetos

Modelar colecciones de datos — listas de cosas, y cosas con varias propiedades a la vez — que es prácticamente la base de toda app real: listas de productos, mensajes, usuarios, tareas.

Antes de empezar

Seguimos con la consola del navegador o node. Hasta ahora hemos trabajado con datos sueltos: un número, un texto. Hoy aprendemos a agrupar muchos datos relacionados en una sola variable, que es como se organiza la información en cualquier aplicación de verdad.

Arrays y sus métodos

Un array es una lista ordenada de valores, entre corchetes y separados por comas. Puede contener cualquier tipo de dato, incluso mezclado.

const frutas = ["manzana", "pera", "uva"];

console.log(frutas[0]);      // "manzana" -> el primer elemento va en la posición 0
console.log(frutas.length); // 3 -> cuántos elementos tiene

Los arrays tienen métodos incorporados muy potentes para transformarlos sin escribir un bucle a mano. Los cuatro que vas a usar constantemente:

map transforma cada elemento y devuelve un array nuevo, del mismo tamaño:

const numeros = [1, 2, 3, 4];
const dobles = numeros.map(n => n * 2);

console.log(dobles); // [2, 4, 6, 8]
console.log(numeros); // [1, 2, 3, 4] -> el original no cambia

filter se queda solo con los elementos que cumplen una condición, y devuelve un array nuevo (posiblemente más corto):

const pares = numeros.filter(n => n % 2 === 0);

console.log(pares); // [2, 4]

find devuelve el primer elemento que cumple una condición — solo uno, no un array — o undefined si ninguno la cumple:

const primerMayorQueDos = numeros.find(n => n > 2);

console.log(primerMayorQueDos); // 3

reduce es el más difícil de los cuatro y el más potente: recorre el array acumulando un único valor final — una suma, un máximo, cualquier cosa. Recibe una función con dos parámetros (el acumulado hasta ahora, y el elemento actual) y un valor inicial:

const suma = numeros.reduce((acumulado, actual) => acumulado + actual, 0);

console.log(suma); // 10  -> (((0+1)+2)+3)+4

El 0 al final es el punto de partida del acumulado. En cada vuelta, reduce llama a la función con el resultado de la vuelta anterior y el siguiente elemento, hasta que no quedan más.

Ninguno de los cuatro modifica el array original

map, filter, find y reduce siempre devuelven algo nuevo y dejan el array de partida intacto. Esto es intencionado: en React y React Native nunca modificamos datos “en su sitio”, siempre creamos versiones nuevas — una costumbre que empieza a formarse aquí.

Objetos y acceso a propiedades

Un objeto agrupa datos relacionados bajo un mismo nombre, cada uno con su propia etiqueta (su “propiedad”). Donde el array ordena por posición (0, 1, 2…), el objeto ordena por nombre.

const alumno = {
  nombre: "Marta",
  nota: 8.5,
  edad: 27,
};

console.log(alumno.nombre);    // "Marta" -> notación con punto
console.log(alumno["nota"]);  // 8.5     -> notación con corchetes

Las dos formas de acceder hacen lo mismo. La notación con punto es la más habitual; la de corchetes hace falta cuando el nombre de la propiedad viene en una variable, en vez de escrito directamente:

const campo = "edad";
console.log(alumno[campo]); // 27 -> alumno.campo NO funcionaría

Los arrays y los objetos se combinan constantemente: un array de objetos es como se representa casi cualquier lista de datos real — alumnos, productos, mensajes.

const alumnos = [
  { nombre: "Marta", nota: 8.5, edad: 27 },
  { nombre: "Luis", nota: 4.2, edad: 31 },
  { nombre: "Sara", nota: 6.9, edad: 22 },
];

console.log(alumnos[0].nombre); // "Marta" -> primero la posición, luego la propiedad

Destructuring y spread/rest

El destructuring extrae propiedades de un objeto (o posiciones de un array) directamente en variables sueltas, sin repetir el nombre del objeto en cada línea:

const { nombre, nota } = alumnos[0];

console.log(nombre); // "Marta"
console.log(nota);   // 8.5

// también funciona con arrays, por posición:
const [primero, segundo] = frutas;
console.log(primero); // "manzana"

Es especialmente útil en los parámetros de una función, para extraer solo lo que necesitas:

function describir({ nombre, edad }) {
  return nombre + " tiene " + edad + " años";
}

console.log(describir(alumnos[0])); // "Marta tiene 27 años"

El spread (...) “desparrama” los elementos de un array o las propiedades de un objeto dentro de otro nuevo — la forma habitual de copiar y modificar sin tocar el original:

const masFrutas = [...frutas, "kiwi"];
console.log(masFrutas); // ["manzana", "pera", "uva", "kiwi"]

const alumnoAprobado = { ...alumnos[1], nota: 5.0 };
console.log(alumnoAprobado); // { nombre: "Luis", nota: 5, edad: 31 }
console.log(alumnos[1].nota); // 4.2 -> el original no cambió

El rest usa la misma sintaxis ... pero en sentido contrario: agrupa el resto de argumentos sobrantes en un array, típicamente en parámetros de función:

function sumarTodos(...numeros) {
  return numeros.reduce((acc, n) => acc + n, 0);
}

console.log(sumarTodos(1, 2, 3, 4)); // 10 -> acepta cualquier cantidad de argumentos

Práctica

Partimos de este array de alumnos. Cópialo tal cual en tu consola antes de empezar:

const alumnos = [
  { nombre: "Marta", nota: 8.5, edad: 27 },
  { nombre: "Luis",  nota: 4.2, edad: 31 },
  { nombre: "Sara",  nota: 6.9, edad: 22 },
  { nombre: "Iván",  nota: 9.8, edad: 19 },
  { nombre: "Noa",   nota: 3.4, edad: 45 },
];

Vas a escribir tres funciones sobre este array, cada una con el método adecuado de los que hemos visto.

1

Filtra los aprobados

Escribe obtenerAprobados, que reciba el array de alumnos y devuelva solo los que tienen nota 5 o más. Es exactamente el trabajo de filter.

function obtenerAprobados(lista) {
  return lista.filter(alumno => alumno.nota >= 5);
}

console.log(obtenerAprobados(alumnos));
// [Marta (8.5), Sara (6.9), Iván (9.8)]
2

Calcula la nota media

Escribe calcularMedia, que devuelva la media de todas las notas. Necesitas sumar todas las notas (reduce) y dividir entre cuántas hay (.length).

function calcularMedia(lista) {
  const sumaNotas = lista.reduce((acc, alumno) => acc + alumno.nota, 0);
  return sumaNotas / lista.length;
}

console.log(calcularMedia(alumnos)); // 6.56
Pista si te atascas

Dentro de reduce, cada “elemento actual” es un objeto alumno completo, no un número — por eso hace falta acceder a alumno.nota dentro de la función.

3

Devuelve solo los nombres

Escribe obtenerNombres, que transforme el array de objetos en un simple array de strings con los nombres. Es el caso de uso más típico de map: cambiar la “forma” de cada elemento.

function obtenerNombres(lista) {
  return lista.map(alumno => alumno.nombre);
}

console.log(obtenerNombres(alumnos));
// ["Marta", "Luis", "Sara", "Iván", "Noa"]
4

Encadénalas

Como las tres devuelven algo nuevo sin tocar el original, se pueden combinar en una sola línea: los nombres de solo los alumnos aprobados.

console.log(obtenerNombres(obtenerAprobados(alumnos)));
// ["Marta", "Sara", "Iván"]

// o encadenando los métodos directamente:
console.log(
  alumnos.filter(a => a.nota >= 5).map(a => a.nombre)
);
// ["Marta", "Sara", "Iván"]
Reto extra

Escribe alumnoConMejorNota usando reduce (no find) para devolver el objeto del alumno con la nota más alta. Luego, usando destructuring y spread, escribe subirNota(alumno, puntos) que devuelva una copia del alumno con la nota incrementada, sin modificar el objeto original — comprueba con console.log que el alumno de partida sigue con su nota de siempre.
