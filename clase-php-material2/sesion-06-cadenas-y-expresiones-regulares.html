Cadenas y expresiones regulares

Funciones de string de uso diario y, para cuando eso no basta, expresiones regulares — buscar y extraer patrones dentro de un texto.

Funciones de string básicas

$texto = "Curso de PHP";

echo strlen($texto);           // 12 -> longitud, en caracteres
echo strtoupper($texto);        // "CURSO DE PHP"
echo strtolower($texto);        // "curso de php"
echo substr($texto, 0, 5);      // "Curso" -> desde la posición 0, 5 caracteres
echo str_replace("PHP", "MySQL", $texto); // "Curso de MySQL"
var_dump(str_contains($texto, "PHP")); // true

Para pasar de texto a array y viceversa, las dos funciones que más vas a usar son explode() (trocea un string por un separador) y implode() (la operación contraria: une un array en un string):

$frase = "el veloz murciélago hindú";

$palabras = explode(" ", $frase);
// ["el", "veloz", "murciélago", "hindú"]

echo implode("-", $palabras);
// "el-veloz-murciélago-hindú"

Expresiones regulares

Una expresión regular describe un patrón de texto, en vez de un texto exacto. En PHP, el patrón siempre va entre delimitadores (normalmente /) al principio y al final.

preg_match() — ¿encaja el patrón?

Comprueba si el patrón aparece en el texto, y (si le pasas un tercer argumento) te devuelve lo encontrado.

$email = "ana@ejemplo.com";

if (preg_match("/^[\w.]+@[\w.]+\.\w+$/", $email)) {
  echo "Formato válido";
}

preg_match("/(\d+)/", "Tengo 32 años", $coincidencias);
echo $coincidencias[0]; // "32" -> lo que ha encontrado el grupo entre paréntesis

preg_replace() — buscar y reemplazar por patrón

$texto = "Teléfono: 611-222-333";
$sinGuiones = preg_replace("/-/", "", $texto);
// "Teléfono: 611222333"

preg_split() — trocear por un patrón

Como explode(), pero el separador puede ser un patrón en vez de un texto fijo — útil cuando el texto puede venir separado por comas, espacios o punto y coma indistintamente.

$datos = "ana, luis;eva  carlos";
$nombres = preg_split("/[\s,;]+/", $datos);
// ["ana", "luis", "eva", "carlos"] -> uno o más espacios, comas o punto y coma seguidos, cuentan como un solo separador

preg_match_all() — todas las coincidencias, no solo la primera

preg_match_all("/\d+/", "3 manzanas, 12 peras y 7 uvas", $todos);
echo implode(", ", $todos[0]); // "3, 12, 7"
No hace falta memorizar la sintaxis de golpe

\d (un dígito), \w (una letra, dígito o guion bajo), \s (un espacio) y + (uno o más) cubren el 80% de los casos que verás en el curso. El resto se busca en la documentación en el momento, como hace cualquier programador con expresiones regulares.

Práctica

Dado un párrafo, extrae el mensaje oculto: la primera letra de la primera palabra, la segunda letra de la segunda palabra, la tercera letra de la tercera palabra, y así hasta el final — en cada palabra, la posición de la letra se calcula con el módulo de su longitud (para no salirte si la palabra es más corta que la posición que toca).

1

Trocea el párrafo en palabras

$parrafo = "el sol brilla sobre el mar en calma";
$palabras = preg_split("/\s+/", trim($parrafo));
2

Recorre las palabras con su posición

Necesitas el índice de cada palabra (0, 1, 2…) a la vez que la palabra en sí, así que aquí foreach con clave viene bien, aunque el array sea indexado:

$mensaje = "";

foreach ($palabras as $indice => $palabra) {
  $posicion = $indice % strlen($palabra);
  $mensaje .= $palabra[$posicion];
}

echo $mensaje;

$palabra[$posicion] accede directamente a un carácter del string por su posición, igual que si fuera un array — funciona porque en PHP los strings se pueden indexar así. .= es “concatena y asigna”: añade al final de $mensaje sin reescribirlo entero.

Compruébalo tú

Con el párrafo de ejemplo de arriba, la palabra número 2 (índice 2) es “brilla” (6 letras): 2 % 6 = 2, así que la letra que toca es la de posición 2, la “i”. Sigue el mismo cálculo a mano con dos o tres palabras más para asegurarte de que lo tienes claro antes de ejecutar el script.
