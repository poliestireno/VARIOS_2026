2 horas Sesión 1/13 XAMPP + VS Code

Antes de empezar

PHP no es como JavaScript en el navegador: el código PHP no lo ejecuta el navegador, lo ejecuta un servidor, y el navegador solo recibe el HTML ya generado. Para programar en PHP en tu propio ordenador necesitas ese servidor funcionando en local — para eso instalamos XAMPP, que trae Apache (el servidor), PHP y MySQL juntos y ya configurados entre sí.

1

Instala XAMPP

Descárgalo desde apachefriends.org e instálalo con las opciones por defecto (Windows/Mac/Linux). Al terminar, abre el Panel de control de XAMPP y pulsa Start en los módulos Apache y MySQL — deberían ponerse en verde. Esos dos procesos tienen que estar arrancados cada vez que trabajes en PHP.

2

Localiza la carpeta htdocs

Apache solo sirve páginas que estén dentro de una carpeta concreta, htdocs, que XAMPP ha creado durante la instalación (por ejemplo C:\xampp\htdocs en Windows, o /Applications/XAMPP/htdocs en Mac). Dentro de htdocs, crea una carpeta para el curso, por ejemplo curso-php. Todo lo que hagas a partir de hoy vive dentro de esa carpeta.

3

Instala VS Code y sus extensiones

Abre esa carpeta curso-php con Archivo → Abrir carpeta… en VS Code, y añade estas 10 extensiones (pestaña de Extensiones, icono de piezas de puzle):

1

PHP Intelephense

Autocompletado, avisos de error mientras escribes e “ir a la definición” de una función o variable. Es la extensión que más vas a notar en el día a día.

2

PHP Debug

Permite poner puntos de ruptura (breakpoints) y ejecutar el código paso a paso, en vez de depurar a base de echo. Usa Xdebug, que XAMPP ya trae incluido.

3

PHP Server

Añade un botón para lanzar un servidor PHP y previsualizar la página sin salir de VS Code ni abrir el navegador a mano cada vez.

4

PHP DocBlocker

Genera automáticamente el comentario de documentación de una función (parámetros, tipo de retorno) al escribir /** justo encima.

5

SQLTools + driver de MySQL

Para consultar la base de datos directamente desde VS Code, sin cambiar de programa. No la necesitarás hasta el bloque 3, pero mejor dejarla instalada ya.

6

live server

Levanta un servidor local con recarga automática del navegador cada vez que guardas un cambio en HTML, CSS o JS. Para PHP usaréis sobre todo el servidor de XAMPP o “PHP Server”, pero viene bien para maquetar sin recargar a mano.

7

auto rename tag

Al cambiar el nombre de una etiqueta HTML de apertura, renombra automáticamente su etiqueta de cierre — evita el descuadre de andar editando las dos por separado.

8

auto close tag

Añade la etiqueta de cierre en cuanto escribes la de apertura, para no acabar con HTML mal cerrado por olvido.

9

css peek

Permite saltar directamente a la definición de una clase o id de CSS desde el HTML que la usa, sin ir a buscarla a mano en el fichero de estilos.

10

prettier

Formatea el código automáticamente al guardar — indentación, comillas, espacios — para mantener un estilo consistente sin pensar en ello.

4

Activa la visualización de errores

Por defecto, PHP a veces oculta sus errores y simplemente no muestra nada — la peor situación posible para aprender. En el Panel de control de XAMPP, botón Config junto a Apache → PHP (php.ini), y cambia estas dos líneas:

display_errors = On
error_reporting = E_ALL

Guarda el archivo y reinicia Apache (Stop y luego Start otra vez en el panel) para que el cambio se aplique.

Por qué esto importa

Con los errores apagados, una página PHP rota simplemente se ve en blanco, sin ninguna pista de qué ha fallado ni en qué línea. Con display_errors activado, PHP te dice exactamente el archivo y la línea del problema — la diferencia entre depurar en segundos o a ciegas.

5

Escribe y ejecuta tu primer script

Crea index.php dentro de htdocs/curso-php:

<!DOCTYPE html>
<html>
<body>
  <h1>
    <?php
      echo "Hola mundo desde PHP";
    ?>
  </h1>
</body>
</html>

Guarda y abre en el navegador http://localhost/curso-php/index.php. Fíjate que no abres el archivo con doble clic ni con file:// — tiene que pasar por localhost, es decir, por Apache, o PHP nunca se ejecuta y verías el código tal cual, sin procesar.

Comprueba que los errores funcionan

Borra a propósito el punto y coma de la línea echo y recarga la página. Deberías ver un error de PHP en pantalla (naranja o rojo, según la versión), con el nombre del archivo y el número de línea exactos. Si ves la página en blanco, vuelve al paso 4.

Islas de PHP dentro de HTML

Un archivo .php es, por defecto, HTML normal. El código PHP solo se ejecuta dentro de las etiquetas <?php y ?> — el resto del archivo, fuera de esas etiquetas, se envía al navegador tal cual, sin tocar. A esto lo llamamos “islas” de PHP: puedes abrir y cerrar tantas como quieras dentro del mismo archivo.

<ul>
  <?php for ($i = 1; $i <= 3; $i++): ?>
    <li>Elemento número <?php echo $i; ?></li>
  <?php endfor; ?>
</ul>

Esta sintaxis con dos puntos (:) y endfor/endif en vez de llaves { } es una alternativa que PHP ofrece específicamente para cuando el código va mezclado con HTML — se lee mejor que anidar llaves entre etiquetas. Es opcional: dentro de un bloque <?php ... ?> sin HTML de por medio, las llaves normales funcionan igual de bien.

echo no es una función

echo es una construcción del lenguaje, no una función: por eso puedes escribir echo "a", "b", "c"; separando varios valores por comas, sin paréntesis. Es lo que vas a usar constantemente para volcar cualquier valor de PHP dentro del HTML.

Pasar datos entre páginas con POST

Un formulario HTML puede enviar sus datos a otra página PHP. Con method="post", esos datos no aparecen en la URL (a diferencia de get) y llegan en un array especial que PHP rellena automáticamente: $_POST.

<!-- formulario.php -->
<form action="saludo.php" method="post">
  <input type="text" name="nombre" placeholder="Tu nombre">
  <button type="submit">Enviar</button>
</form>
<!-- saludo.php -->
<?php
  $nombre = $_POST['nombre'];
?>
<h1>Hola, <?php echo $nombre; ?></h1>

El nombre entre corchetes ('nombre') tiene que coincidir exactamente con el atributo name del <input> — es la clave que conecta el formulario con la página que recibe los datos.

Compruébalo tú

Deja el campo nombre vacío y pulsa enviar. $_POST['nombre'] existe igualmente, pero con el valor "" (cadena vacía) — no confundas “vacío” con “no enviado”, es una distinción que importa mucho más adelante, con formularios de login.

Práctica

Crea dos archivos dentro de tu carpeta del curso.

1

formulario.php

Un formulario con dos campos: nombre (texto) y edad (número), que envía por POST a resultado.php.

2

resultado.php

Recoge los dos valores de $_POST y muestra una frase como “Hola <nombre>, el año que viene tendrás <edad + 1> años” — usando al menos una isla de PHP y una suma con el valor recibido.

Reto extra

$_POST siempre llega como texto, incluso el campo edad. Prueba a sumarle 1 directamente ($_POST['edad'] + 1) y comprueba que, sorprendentemente, funciona igual — PHP convierte el texto a número automáticamente en operaciones aritméticas. Lo veremos con detalle en la sesión 2.
