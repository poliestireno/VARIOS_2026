Arrays indexados

Un array indexado guarda una lista ordenada de valores, cada uno accesible por su posición numérica, empezando en 0:

$colores = ["rojo", "verde", "azul"];

echo $colores[0]; // "rojo"
echo count($colores); // 3

$colores[] = "amarillo"; // añade al final, sin indicar índice
$colores[1] = "lima";    // sobrescribe la posición 1 ("verde" -> "lima")

count() te da el número de elementos, y $array[] = valor es la forma habitual de ir construyendo un array dentro de un bucle, añadiendo un elemento cada vez.

Arrays asociativos

Un array asociativo usa texto como clave, en vez de un número de posición — útil para representar algo parecido a un objeto: cada clave tiene un significado propio.

$alumno = [
  "nombre" => "Ana",
  "edad"   => 22,
  "curso"  => "PHP",
];

echo $alumno["nombre"]; // "Ana"
$alumno["edad"] = 23; // se actualiza igual que en un array indexado

El operador => (una flecha, no un signo “mayor o igual que”) es el que separa cada clave de su valor. Puedes comprobar si una clave existe con array_key_exists(), o si falta directamente con isset().

Recorrer arrays con foreach

Para un array indexado, foreach te da directamente cada valor:

foreach ($colores as $color) {
  echo $color . " ";
}

Para un array asociativo, puedes pedir también la clave junto al valor:

foreach ($alumno as $clave => $valor) {
  echo "$clave: $valor<br>";
}
// nombre: Ana
// edad: 23
// curso: PHP
Orden de recorrido

foreach siempre recorre un array asociativo en el orden en que se insertaron las claves — no alfabético, no numérico — el mismo orden en que aparecen escritas en el código (o en el que se fueron añadiendo, si se construyó dentro de un bucle).

Funciones básicas de array

$numeros = [5, 2, 8, 1];

echo count($numeros);          // 4
var_dump(in_array(8, $numeros)); // true
sort($numeros);                // ordena y RE-INDEXA de 0 en adelante
// $numeros ahora es [1, 2, 5, 8]

$claves  = array_keys($alumno);   // ["nombre", "edad", "curso"]
$valores = array_values($alumno); // ["Ana", 23, "PHP"]

array_keys() y array_values() son exactamente lo que necesitas cuando quieres las claves y los valores de un array asociativo por separado — como en el ejercicio de hoy.

Práctica

Dado un array asociativo de 12 elementos (clave/valor de la temática que quieras — por ejemplo, meses del año y sus días), imprime en HTML, desde PHP:

1

Dos matrices 3×4

Una tabla con las 12 claves distribuidas en 3 filas de 4 columnas, y otra tabla igual pero con los 12 valores.

2

Las mismas dos matrices, en formato 6×2

Las mismas claves y valores, pero ahora en 6 filas de 2 columnas — sin tocar el array original, solo cambiando cómo lo recorres.

3

Pista: separa claves y valores primero

$claves = array_keys($datos);
$valores = array_values($datos);

echo "<table>";
for ($fila = 0; $fila < 3; $fila++) {
  echo "<tr>";
  for ($col = 0; $col < 4; $col++) {
    $indice = $fila * 4 + $col;
    echo "<td>" . $claves[$indice] . "</td>";
  }
  echo "</tr>";
}
echo "</table>";

La fórmula clave es $fila * numeroDeColumnas + $col: convierte una posición (fila, columna) en el índice correspondiente dentro del array plano de 12 elementos.

Reto extra

Convierte la parte que dibuja la tabla en una función dibujarMatriz($lista, $filas, $columnas) reutilizable, y llámala cuatro veces (claves 3×4, valores 3×4, claves 6×2, valores 6×2) en vez de repetir el bucle a mano cuatro veces.
