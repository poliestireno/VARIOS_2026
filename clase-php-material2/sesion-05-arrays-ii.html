Ordenar

PHP tiene varias funciones de ordenación según lo que quieras conservar: sort() ordena valores y reindexa desde 0 (pierdes las claves originales); asort() ordena valores pero conserva las claves; ksort() ordena por clave.

$precios = ["pan" => 1.2, "leche" => 0.9, "huevos" => 2.5];

asort($precios);  // ordena por valor, de menor a mayor, conservando las claves
// ["leche" => 0.9, "pan" => 1.2, "huevos" => 2.5]

ksort($precios);  // ordena por clave, alfabéticamente
// ["huevos" => 2.5, "leche" => 0.9, "pan" => 1.2]
Todas ordenan “en el sitio”

Ninguna de estas funciones devuelve un array nuevo: modifican directamente la variable que les pasas (por eso no hace falta reasignar con $precios = sort($precios), y de hecho eso rompería el resultado, porque sort() devuelve true/false, no el array).

Filtrar y transformar

array_filter() se queda solo con los elementos que cumplen una condición; array_map() aplica una transformación a cada elemento. A diferencia de sort(), estas dos sí devuelven un array nuevo.

$numeros = [1, 2, 3, 4, 5, 6];

$pares = array_filter($numeros, function ($n) {
  return $n % 2 === 0;
});
// [1 => 2, 3 => 4, 5 => 6] -> ¡ojo! conserva los índices originales

$dobles = array_map(function ($n) {
  return $n * 2;
}, $numeros);
// [2, 4, 6, 8, 10, 12]

La función que le pasas a array_filter() o array_map() como segundo argumento es una función anónima: una función sin nombre, definida justo ahí donde se usa. Es exactamente el mismo concepto que un “callback” en JavaScript.

Índices tras array_filter

array_filter() deja “huecos” en la numeración, como se ve arriba (1 => 2, no 0 => 2). Si necesitas un array indexado de 0 en adelante otra vez, envuélvelo en array_values($pares).

Arrays multidimensionales

Un array puede contener otros arrays dentro — la forma habitual de representar una tabla, o una lista de “objetos” con varios campos cada uno.

$alumnos = [
  ["nombre" => "Ana",  "nota" => 8.5],
  ["nombre" => "Luis", "nota" => 6.0],
  ["nombre" => "Eva",  "nota" => 9.2],
];

echo $alumnos[0]["nombre"]; // "Ana" -> primer nivel: posición; segundo nivel: clave

foreach ($alumnos as $alumno) {
  echo $alumno["nombre"] . ": " . $alumno["nota"] . "<br>";
}

Este patrón — una lista de arrays asociativos, todos con las mismas claves — es exactamente la forma en la que verás llegar los datos desde una base de datos a partir de la sesión 7. Lo que aprendas hoy se reutiliza directamente allí.
