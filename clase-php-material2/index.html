Bloque 1

Fundamentos de PHP

Sesiones 1–4 · Semanas 1–4

Entorno de trabajo y la base del lenguaje: sin esto, ni el código se puede ejecutar en local ni tiene sentido lo que viene después.

1

Entorno de desarrollo y primer script

Tener PHP funcionando en local y escribir la primera página que combine HTML y PHP.

Contenido: instalar XAMPP (Apache + PHP + MySQL) y activar la visualización de errores; instalar VS Code y sus extensiones básicas para PHP — PHP Intelephense (autocompletado e ir a definición), PHP Debug (depurar con Xdebug), PHP Server (previsualizar sin salir del editor), PHP DocBlocker (documentar funciones) y SQLTools + su driver de MySQL (consultar la base de datos desde el propio VS Code); “islas” de PHP dentro de un HTML.

Práctica: primer “hola mundo” en PHP y una página que recibe datos de un formulario por POST.

2

Sintaxis PHP I

Escribir código PHP con soltura: variables, tipos, operadores y funciones propias.

Contenido: etiquetas de apertura/cierre, tipos de datos, operadores, constantes, funciones, paso de parámetros por valor y por referencia.

Práctica: función que reciba tres operandos y un operador, y devuelva el resultado por referencia.

3

Control de flujo

Tomar decisiones y repetir instrucciones.

Contenido: condicionales (if, switch, operador ternario), bucles (while, do-while, for, foreach).

Práctica: dado un número N, imprimir un triángulo de asteriscos centrado de altura N.

4

Arrays I

Guardar y recorrer colecciones de datos.

Contenido: arrays indexados y asociativos, recorrido con foreach, funciones básicas de array.

Práctica: a partir de un array asociativo de 12 elementos, imprimir en HTML sus claves y valores como dos matrices (3×4 y 6×2).

Bloque 2

Arrays y cadenas

Sesiones 5–6 · Semanas 5–6

Se cierra la caja de herramientas del lenguaje antes de tocar datos reales: más funciones de array y todo lo necesario para procesar texto.

5

Arrays II

Profundizar en las funciones de array de uso diario.

Contenido: ordenar, filtrar y transformar arrays, arrays multidimensionales.

Práctica: ampliar el ejercicio de arrays de la sesión anterior con una función de ordenación propia.

6

Cadenas y expresiones regulares

Manipular texto y extraer patrones de una cadena.

Contenido: funciones de string, expresiones regulares con preg_match(), preg_replace(), preg_split() y preg_match_all().

Práctica: dado un párrafo, extraer un mensaje oculto combinando una letra de cada palabra según su posición. ▶ vídeo

Bloque 3

Bases de datos

Sesiones 7–9 · Semanas 7–9

PHP deja de trabajar solo con datos inventados en el propio código y empieza a hablar con una base de datos MySQL real.

7

Bases de datos en PHP I

Conectar PHP con MySQL y traer los primeros datos.

Contenido: conexión con PDO, sentencias SELECT, sentencias preparadas.

Práctica: consultar una tabla y mostrar el resultado por pantalla. ▶ vídeo

8

Bases de datos en PHP II

Mostrar y filtrar datos reales de forma vistosa.

Contenido: volcar el resultado de una consulta en una tabla HTML, filtros por varios campos.

Práctica: página de listado con filtros por al menos dos campos distintos. ▶ vídeo

9

Bases de datos en PHP III

Cerrar el ciclo completo de operaciones sobre una tabla.

Contenido: INSERT, UPDATE y DELETE con sentencias preparadas.

Práctica: formulario de alta, edición y borrado sobre la tabla de la sesión anterior. ▶ vídeo

Bloque 4

Sesiones y autenticación

Sesiones 10–11 · Semanas 10–11

Una aplicación de verdad necesita saber quién está al otro lado. Se añade login, control de acceso y estado entre páginas.

10

Sesión en PHP I

Identificar a un usuario a lo largo de varias páginas.

Contenido: tabla de usuarios, formulario de login, $_SESSION, validar credenciales correctas e incorrectas.

Práctica: login funcional contra una tabla de usuarios en base de datos. ▶ vídeo

11

Sesión en PHP II

Completar el ciclo de vida de la sesión de un usuario.

Contenido: cerrar sesión programáticamente, proteger páginas frente a accesos sin login, expiración de la sesión por tiempo.

Práctica: ampliar el login anterior con cierre de sesión, páginas protegidas y una segunda página dentro del área privada. ▶ vídeo

Bloque 5

Proyecto final

Sesiones 12–13 · Semanas 12–13

Todo lo visto hasta ahora — PHP, base de datos y sesión — se junta en una aplicación propia, de principio a fin.

12

Definición y diseño del proyecto

Pasar de una idea a un diseño técnico realista.

Contenido: diagrama entidad-relación de la base de datos, reparto entre vista de administración y vista de cliente, lista de páginas necesarias.

Práctica: entrega del diseño de la base de datos (script SQL o diagrama).

13

Desarrollo y presentación del proyecto

Construir y enseñar la aplicación completa.

Contenido: páginas de gestión (listar, insertar, modificar, borrar) y área de cliente (registro, login y perfil).

Práctica: demo final del proyecto con su repositorio de código y capturas de la ejecución.

Los bloques 1 y 2 son intencionadamente independientes de la base de datos — primero el lenguaje, después los datos reales — para no mezclar la curva de aprendizaje de PHP con la de SQL a la vez. El bloque 5 reutiliza directamente las bases de datos y la sesión de usuario de los bloques 3 y 4 como cierre natural del curso.
