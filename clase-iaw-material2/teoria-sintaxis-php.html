01

Variables y tipos de datos

En PHP toda variable empieza por $ y no necesita declarar su tipo — se infiere del valor asignado (tipado dinámico).

$nombre = "Ana";      // string
$edad = 30;             // int
$precio = 19.95;        // float
$activo = true;         // bool
$sin_valor = null;       // null

Dentro de cadenas entre comillas dobles, las variables se interpolan directamente: "Hola $nombre". Entre comillas simples no — se mostraría literalmente $nombre.

02

Operadores

Aritméticos (+ - * / % **), de comparación (== != > < >= <=), y de comparación estricta (=== !==), que además de valor compara tipo.

var_dump(0 == "a");   // false en PHP moderno (antes daba problemas)
var_dump("5" == 5);   // true: compara solo el valor
var_dump("5" === 5);  // false: distinto tipo (string vs int)

El operador de fusión de null ?? es muy habitual al leer datos externos: $_GET['pagina'] ?? 1 usa 1 si esa clave no existe, sin lanzar un aviso.

03

Constantes

define('IVA', 0.21);
echo IVA; // sin el símbolo $, y su valor no puede cambiar después
04

Funciones

function calcularTotal($precio, $cantidad = 1) {
  return $precio * $cantidad;
}

echo calcularTotal(10);     // 10, usa el valor por defecto de $cantidad
echo calcularTotal(10, 3);  // 30

Los parámetros pueden tener un valor por defecto ($cantidad = 1), que se usa cuando el argumento no se pasa en la llamada.

05

Paso por valor y por referencia

Por defecto, los argumentos se pasan por valor: la función recibe una copia, y modificarla dentro no afecta a la variable original. Con & delante del parámetro, se pasa por referencia: la función opera sobre la variable original.

function duplicar(&$numero) {
  $numero *= 2;
}

$x = 5;
duplicar($x);
echo $x; // 10 — sin el &, seguiría siendo 5
06

Condicionales

if ($edad >= 18) {
  echo "Mayor de edad";
} elseif ($edad >= 13) {
  echo "Adolescente";
} else {
  echo "Menor";
}

switch ($dia) {
  case 1: echo "Lunes"; break;
  case 7: echo "Domingo"; break;
  default: echo "Entre semana";
}
07

Bucles

for ($i = 0; $i < 5; $i++) {
  echo $i;
}

$i = 0;
while ($i < 5) {
  echo $i;
  $i++;
}

Los bucles anidados (uno dentro de otro) son la base de cualquier lógica sobre una cuadrícula — filas y columnas, tablero de juego, matriz… el bucle exterior recorre las filas, el interior las columnas de cada fila.

Con esto ya se puede escribir cualquier lógica de servidor. El siguiente paso es Arrays y cadenas en PHP.
