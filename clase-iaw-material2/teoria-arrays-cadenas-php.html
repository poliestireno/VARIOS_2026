01

Arrays indexados

$colores = ["rojo", "verde", "azul"];
echo $colores[0];  // "rojo" — el índice empieza en 0
$colores[] = "amarillo"; // añade al final
02

Arrays asociativos

$persona = [
  "nombre" => "Ana",
  "edad" => 30,
];
echo $persona["nombre"]; // "Ana" — se accede por clave, no por posición
03

Recorrer arrays con foreach

foreach ($colores as $color) {
  echo $color;
}

foreach ($persona as $clave => $valor) {
  echo "$clave: $valor";
}
04

Funciones básicas de array

count() (número de elementos), in_array() (¿existe ese valor?), array_search() (posición de un valor), array_keys() / array_values() (claves o valores por separado), array_merge() (unir dos arrays).

05

Ordenar, filtrar y transformar

sort($numeros);          // ordena y reindexa desde 0
rsort($numeros);         // orden descendente
asort($persona);         // ordena un asociativo, conservando las claves

$pares = array_filter($numeros, fn($n) => $n % 2 === 0);
$dobles = array_map(fn($n) => $n * 2, $numeros);

array_filter() se queda solo con los elementos que cumplen la condición; array_map() transforma cada elemento en otro nuevo, generando un array del mismo tamaño.

06

Arrays multidimensionales

$matriz = [
  [1, 2, 3],
  [4, 5, 6],
];
echo $matriz[1][2]; // 6 — fila 1, columna 2

foreach ($matriz as $fila) {
  foreach ($fila as $celda) {
    echo $celda . " ";
  }
}

Un tablero de juego 10×10 (como en un buscaminas o una batalla naval) es, precisamente, un array multidimensional: $tablero[$fila][$columna].

07

Funciones de string básicas

strlen() (longitud), strtoupper()/strtolower(), trim() (quita espacios de los extremos), str_replace() (buscar y reemplazar texto literal), explode() (trocea una cadena por un separador, devuelve array), implode() (la operación inversa: une un array en una cadena).

08

Expresiones regulares

Cuando str_replace() se queda corto (hace falta un patrón, no un texto literal), entran las expresiones regulares:

  • preg_match(): ¿encaja el patrón en la cadena? Devuelve 1 (sí) o 0 (no).
  • preg_replace(): busca y reemplaza por patrón, no por texto exacto.
  • preg_split(): trocea una cadena por un patrón (como explode(), pero con patrones en vez de un separador fijo).
  • preg_match_all(): todas las coincidencias del patrón, no solo la primera.
if (preg_match('/^[a-z0-9_]+$/', $usuario)) {
  echo "Usuario válido";
}

$palabras = preg_split('/\s+/', $parrafo);
// trocea por cualquier cantidad de espacios seguidos
