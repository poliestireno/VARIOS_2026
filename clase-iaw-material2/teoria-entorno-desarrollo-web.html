01

Instalar XAMPP

XAMPP empaqueta en un único instalador todo lo necesario para servir PHP en local: Apache (servidor web), MySQL/MariaDB (base de datos), PHP y Perl. Tras instalarlo, el Panel de Control de XAMPP permite arrancar y parar Apache y MySQL con un botón.

El directorio raíz donde colocar los proyectos es htdocs (en Linux, típicamente /opt/lampp/htdocs) — todo lo que se guarda ahí es accesible desde el navegador en http://localhost/.

02

El primer script PHP

Un fichero .php puede mezclar HTML normal con bloques de código PHP, delimitados por <?php y ?>. Todo lo que hay fuera de esas etiquetas se envía tal cual al navegador; lo que hay dentro lo ejecuta el servidor antes de responder.

<!DOCTYPE html>
<html>
<body>
  <h1><?php echo "Hola desde PHP"; ?></h1>
</body>
</html>

El navegador nunca ve el código PHP — solo el HTML resultante, ya con los valores calculados. Se comprueba abriendo la URL correspondiente dentro de htdocs, no abriendo el archivo directamente con doble clic (eso solo mostraría el código fuente, sin pasar por Apache).

03

VS Code y sus extensiones

Diez extensiones cubren el día a día de un proyecto PHP + HTML + CSS:

  • PHP Intelephense: autocompletado, avisos de error mientras escribes, e “ir a la definición”.
  • PHP Debug: breakpoints y ejecución paso a paso con Xdebug (incluido en XAMPP).
  • PHP Server: botón para lanzar un servidor PHP y previsualizar sin salir del editor.
  • PHP DocBlocker: genera el comentario de documentación de una función al escribir /**.
  • SQLTools + driver de MySQL: consultar la base de datos sin cambiar de programa.
  • Live Server: recarga automática del navegador al guardar HTML/CSS/JS.
  • Auto Rename Tag: renombra la etiqueta de cierre al cambiar la de apertura.
  • Auto Close Tag: añade la etiqueta de cierre en cuanto escribes la de apertura.
  • CSS Peek: salta a la definición de una clase o id de CSS desde el HTML.
  • Prettier: formatea el código automáticamente al guardar.

04

Activar la visualización de errores

Por defecto, PHP a veces oculta sus errores y simplemente no muestra nada — la peor situación posible mientras se desarrolla. En el Panel de Control de XAMPP, botón Config junto a Apache → PHP (php.ini), y cambia estas dos líneas:

display_errors = On
error_reporting = E_ALL

Guarda el archivo y reinicia Apache (Stop y luego Start otra vez en el panel) para que el cambio se aplique.

Con el entorno listo, pon en práctica esta primera configuración en el desafío RA15_EXTENSIONES_VSC_IAW.
