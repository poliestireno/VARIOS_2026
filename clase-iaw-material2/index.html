Bloque 1 · 50% de la evaluación

RA1 + RA5 · Entorno y documentos con guiones de servidor

3 desafíos · Eval. 1

RA1. Prepara el entorno de desarrollo y los servidores de aplicaciones Web instalando e integrando las funcionalidades necesarias. RA5. Genera documentos Web utilizando lenguajes de guiones de servidor.

Teoría

T0

La máquina virtual de desarrollo

Antes de empezar: instalar VirtualBox, montar una VM con Linux Mint XFCE (4 GB RAM, 20-25 GB de disco), y dejar dentro el stack de desarrollo completo (VS Code, Python, Apache, MariaDB, PHP).

T1

Entorno de desarrollo web

XAMPP, el primer script que mezcla HTML y PHP, las diez extensiones de VS Code para el día a día, y cómo activar la visualización de errores.

T2

Sintaxis de PHP y control de flujo

Variables y tipos, operadores, constantes, funciones propias y paso por referencia, condicionales y bucles.

T3

Arrays y cadenas en PHP

Arrays indexados y asociativos, foreach, ordenar/filtrar/transformar, matrices multidimensionales, funciones de string y expresiones regulares.

Desafíos

D1

RA15_EXTENSIONES_VSC_IAW

Monta el entorno de desarrollo completo: XAMPP, VS Code con sus diez extensiones, activación de errores, y el primer script PHP funcionando en local.

D2

RA15_DA2

Desafío con enunciado en vídeo: implementación en PHP con entrega de código y un vídeo de ejecución de menos de un minuto.

D3

RA15_DOS_MANOS_POKER

Página PHP que reparte dos manos de póker aleatorias (con repetición) de cinco cartas, muestra las imágenes de las cartas, y determina quién gana — con detección opcional de pareja, doble pareja o trío mostrada en un SweetAlert.

Bloque 2 · 50% de la evaluación

RA4 + RA6 · Ofimática web y acceso a bases de datos

5 desafíos · Eval. 2

RA4. Gestiona aplicaciones de ofimática Web integrando funcionalidades y asegurando el acceso a la información. RA6. Genera documentos Web con acceso a bases de datos utilizando lenguajes de guiones de servidor.

Teoría

T4

PHP y bases de datos

Conexión con PDO, sentencias preparadas, tablas HTML con filtro, y el ciclo completo de alta, edición y borrado sobre una tabla.

T5

Sesiones en PHP

password_hash()/password_verify(), login, proteger páginas frente a accesos sin sesión, expiración por inactividad, logout, y roles de usuario.

T6

Redis desde PHP: caché y políticas de reemplazo

php-redis, el patrón de caché delante de MySQL, y cinco políticas de reemplazo: actualización inmediata, invalidación, TTL, lazy loading y GilRan.

Desafíos

D4

RA46_DB_GAMES_PHP

Base de datos de juegos, jugadores y partidas (PLAYERS, GAMES, PARTIDAS), con páginas PHP de listado, alta, edición y borrado para cada tabla, más una página inicial con un resumen de control.

D5

RA46_REDIS_CHALLENGE_FASE02

Redis desde PHP con la extensión php-redis: conexión, hashes y listas, la app “Aceitunas” con MySQL + caché TTL, y su extensión con un panel de control web para elegir entre cinco políticas de reemplazo de caché.

D6

RA46_PIRATA_RATANEGRA_PHP

“El mar del Capitán Ratanegra”: un buscaminas naval en PHP/HTML/CSS con matriz 10×10, barcos de distintos tamaños, tesoros y bombas ocultos, tres niveles de dificultad, y condiciones de victoria y derrota.

D7

RA46_APP_SESSION_PHP

Web app con registro, login con contraseña cifrada, roles de superusuario y usuario normal, sesión protegida con expiración a los 5 minutos de inactividad, un juego del número oculto con ranking, y diseño previo del modelo relacional.

D8

RA46_NAVAPARK2

Sistema de gestión para un parque de atracciones: base de datos relacional de atracciones, viajeros y viajes; vista admin con control general y CRUD de atracciones; vista cliente con registro, registro de viajes propios y perfil con el historial de atracciones montadas.
